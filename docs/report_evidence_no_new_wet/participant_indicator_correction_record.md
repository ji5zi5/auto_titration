# 약산-약염기 지시약 메타데이터 정정 기록

- 대상 run: `session-14`, `session-15`, `session-16`
- 원본 CSV 기록: `indicator=methyl_orange`
- 연구 수행자 사후 확인: 실제 사용 지시약은 `BTB(bromothymol blue)`였음
- 사후 확인 기록일: 2026-08-05
- 검증 상태: 당시 실험일지·시약 사진 등 run과 직접 연결되는 동시기 1차 기록을 현재 자료에서 찾지 못했으므로 **독립적으로 검증된 정정이 아님**
- 처리 원칙: 원본 CSV는 수정하지 않는다. 보고서에서는 `연구 수행자 사후 확인에 따른 미독립검증 정정`으로만 표시한다.

이 문서는 원본 메타데이터보다 BTB가 확실하다고 새로 입증하는 자료가 아니다. 상충하는 기록의 출처와 현재 확인 수준을 남기기 위한 추적 문서이다.

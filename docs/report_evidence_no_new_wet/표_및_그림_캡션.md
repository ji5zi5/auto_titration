# 4차 컨설팅 반영 표·그림 캡션

## [표 1] 기존 습식 실험 자료의 범위

| 구분 | 값 | 해석 제한 |
|---|---:|---|
| 습식 적정 run | 12 | 새 실험이 아닌 기존 자료 |
| 저장 행 | 1,822 | 프레임·시계열 행이며 독립 실험 표본 수가 아님 |
| 적정 조합 | 4종 | 각 조합당 농도 3조건 |
| 조건별 반복 | 1회 | 조건별 반복성·재현성 산출 불가 |

**캡션.** 해시로 식별한 원본 CSV 12개의 1,822개 행을 재분석했으며, 새로운 습식 실험이나 독립 검증은 추가하지 않았다.

## [표 2] 센서 입력군별 고정 seed 개발 결과

| 입력군 | MAE (mL) | RMSE (mL) | MAPE (%) |
|---|---:|---:|---:|
| 색상 | 0.548 | 0.754 | 1.55 |
| 열화상 | 0.917 | 1.267 | 3.66 |
| 색상+열화상 | 0.476 | 0.831 | 1.52 |

**캡션.** 현재 주입량을 모델 특징에서 제외한 12개 run의 입력군별 결과. 1.52%는 같은 개발 자료에서 모델과 세부 설정을 선택해 얻은 고정 seed MAPE이며, 독립 검증값이 아니다.

## [표 2-1] 적정 종류 조건부 센서 후보 모델 결과

| 항목 | 결과 |
|---|---:|
| MAE | 0.078 mL |
| RMSE | 0.091 mL |
| MAPE | 0.30% |
| 상대오차 1% 이내 | 12/12 run |
| 상대오차 2% 이내 | 12/12 run |

**캡션.** 실험 전에 알려지는 적정 종류만 모델 선택 조건으로 사용하고, 현재 주입량·이론 당량점·시간·진행률·미지 시료 농도·지시약을 추론 특징에서 제외한 결과. 각 평가 run은 해당 후보 평가기의 학습과 스케일링에서 제외했다. 적정 종류별 평가기와 세부 설정은 총 2,030,370개 조합을 같은 12개 개발 run에서 선택했으며 후보 오라클과 같은 MAPE에 도달했으므로 독립 검증값은 아니다.

## [표 3] 색상 APE 대비 융합 APE의 주 짝지은 비교

| 항목 | 결과 |
|---|---:|
| 주 추정량 | 색상 APE - 융합 APE |
| 평균 개선량 | 0.0275599 pp |
| 적정 종류 층화 run-level bootstrap | 100,000회 |
| 주 95% 구간 | [-1.204831, 1.147784] pp |
| 정확 양측 부호 뒤집기 p값 | 0.978027 |
| 정확 양측 부호 검정 p값 | 0.774414 |
| 융합 개선 / 악화 | 7 / 5 run |
| 부차 평균 부피 개선량 | 0.0715095 mL |
| 부차 층화 95% 구간 | [-0.322663, 0.438838] mL |

**캡션.** 양수인 개선량은 융합 APE가 색상 APE보다 작음을 뜻한다. 주·부차 95% 구간은 모두 0을 포함했고, 융합은 7/12 run에서 개선되고 5/12 run에서 악화되었다. 현재 자료만으로 융합의 일관된 우수성을 확정하기는 어렵고, 제시한 구간은 선택된 개발 모델을 기준으로 계산하였다.

## [표 6] 주 운영적 종말점-기저 대비도 정의

| 항목 | 고정 정의 |
|---|---|
| 기저 구간 | 0.05 ≤ V/Veq ≤ 0.20 |
| 종말점 구간 | 0.95 ≤ V/Veq ≤ 1.05 |
| 부호 대비 신호 | median(종말점) - median(기저) |
| 운영적 잡음 | 1.4826 × MAD(기저) |
| 운영적 대비도 | \|부호 중앙값 차이\| / (1.4826 × MAD) |
| 제외 규칙 | 이용 가능한 ROI 요약값이 모두 0인 행 |
| 제외된 행 | 11 |
| 주 규의 유효 run | 12/12 |

**캡션.** 기저와 명목 이론 당량점 근처의 온도 대비를 중앙값과 MAD로 요약한 운영적 지표. 이 값은 정해진 자료 구간의 operational contrast-to-noise이며, 열화상 카메라 기기 자체의 신호대잡음비 측정값이 아니다.

## [표 7] 종말점 구간 민감도

| 종말점 구간 | 대비도 산출 가능 run | 융합 APE 개선량과의 탐색적 Spearman ρ |
|---|---:|---:|
| 0.95 ≤ V/Veq ≤ 1.05 | 12/12 | -0.223776 |
| 명목 이론 당량점 ±0.5 mL | 1/12 | 산출하지 않음 |
| 명목 이론 당량점 ±1.0 mL | 12/12 | -0.251748 |
| 명목 이론 당량점 ±2.0 mL | 12/12 | -0.265734 |

**캡션.** 종말점 구간을 바꾼 민감도 분석. ±0.5 mL 구간은 최소 종말점 행 수를 충족한 run이 1개에 그쳐 순위상관을 산출하지 않았다. 이 분석은 탐색적이며 운영적 대비도의 예측력을 입증하지 않는다.

**사용 파일:** `data/analysis/report_evidence_no_new_wet/thermal_contrast_by_run.png`

**캡션.** 0.05 ≤ V/Veq ≤ 0.20을 기저, 0.95 ≤ V/Veq ≤ 1.05를 종말점 구간으로 두고, 부호 중앙값 차이의 절대값을 1.4826×MAD로 나눈 run별 운영적 대비도. 모든 ROI 요약값이 0인 행 11개는 제외했다. 이는 사후 운영 지표이며 기기 신호대잡음비가 아니다.

## [그림 3] 운영적 대비도와 융합 APE 개선량

**사용 파일:** `data/analysis/report_evidence_no_new_wet/thermal_contrast_vs_fusion_improvement.png`

**캡션.** 주 구간의 운영적 대비도와 색상 APE - 융합 APE의 run별 관계. Spearman ρ는 -0.223776이고, 고정 seed 100,000회 탐색적 비보정 순열 검정의 p값은 0.485015였다. 이 그림은 운영적 대비도가 융합 개선량을 예측함을 보여 주지 않는다.

# 조밀 집계 탐색과 고정 재현 기록

이 폴더는 적정 종류별 후보 평가기를 고정한 뒤 후보 집계 설정을 추가로 탐색한 결과와, 최종 설정을 별도 재현 스크립트로 다시 실행한 결과를 보존한다.

## 재현 결과

- 개발 자료: 기존 습식 적정 12회
- MAE: 0.077543 mL
- RMSE: 0.090773 mL
- MAPE: 0.295000%
- 최대 절대오차: 0.156127 mL
- 상대오차 1% 이내: 12/12회
- 세 지정 숫자에서 예측 벡터 동일: 결정론적 반복 확인일 뿐 seed 강건성 근거가 아님

## 해석 범위

각 평가 run은 해당 후보 평가기의 학습과 스케일링에서 제외했다. 그러나 적정 종류별 최종 설정은 초기 1,006,020개와 조밀 집계 1,024,350개, 합계 2,030,370개 설정을 같은 12회 개발 결과에서 비교하여 골랐다. 최종 MAPE는 후보 오라클 MAPE와 같으므로 새 시료의 독립 검증 정확도가 아니라 개발 자료 내부의 사후 선택 결과로만 사용한다.

## 파일

- `dense_search_summary.json`: 조밀 집계 탐색 전체 결과
- `reproduction_summary.json`: 고정 설정 별도 재현과 누수 감사
- `exact_predictions.csv`: 12회 정확한 예측·오차와 학습 경로
- `predictions_by_seed.csv`: 결정론적 반복 확인용 예측 벡터
- `per_seed_metrics.csv`: 반복 실행별 동일 지표
- `final_evaluator_summary.json`: 보고서용 최종 평가기 전체 감사 정보
- `final_evaluator_report.md`: 최종 평가기 자동 생성 요약
- `SHA256SUMS`: 위 산출물의 무결성 해시

# 4차 컨설팅 반영 보고서 교체 문안

> 적용 범위: 기존 습식 실험 12회와 이에서 생성한 재분석 산출물만 사용한다. 새 습식 실험이나 독립 검증을 실시했다고 쓰지 않는다.

## 1. 연구 범위와 검증 수준

본 분석에는 실제 적정에서 저장한 12개 run, 1,822개 행을 이용하였다. 각 적정 종류·농도 조건은 한 번씩만 측정되었으므로, 이 자료로는 반복성이나 재현성을 정량화할 수 없다. 모델과 세부 설정도 같은 12개 run에서 선택했으므로, 제시한 오차는 새로운 미지 시료에 대한 일반화 성능이 아니라 **개발 자료 내부 평가 결과**이다.

## 2. 지시약 기록 정정

약산-약염기 적정 3회(`session-14~16`)는 연구 수행자의 사후 확인에 따르면 **BTB(bromothymol blue)**를 사용했다. 그러나 원본 CSV에는 `methyl_orange`로 기록되어 있고, 현재 자료에서 당시 실험일지나 시약 사진처럼 각 run과 직접 연결되는 1차 기록을 찾지 못했다. 따라서 원본 CSV는 수정하지 않고 보존했으며, BTB는 **연구 수행자 사후 확인에 따른 미독립검증 정정**으로만 표시했다.

## 3. 센서 입력군 비교

현재 주입량을 모델 특징에서 제외하고 같은 12개 run의 센서 입력군을 비교했다. 선택된 고정 seed 개발 결과에서 색상 특징의 MAPE는 1.55%, 열화상 특징의 MAPE는 3.66%, 색상+열화상 융합 특징의 MAPE는 1.52%였다. 융합 모델의 MAE는 0.476 mL, RMSE는 0.831 mL였고, 색상 모델의 MAE와 RMSE는 각각 0.548 mL, 0.754 mL였다. 융합 모델은 색상 모델보다 MAE와 MAPE는 조금 낮았지만 RMSE는 더 높았다.

이 1.52%는 선택된 고정 seed에서 얻은 **개발 자료 내부 MAPE**이며 독립 검증 정확도가 아니다. 고정한 융합 방법의 seed 민감도 점검에서, 기준에 사용한 seed 42의 MAPE는 1.52%였지만 다른 고정 seed에서는 8.52%와 8.14%로 변했다. 같은 세 seed의 확률을 평균한 융합 점검값은 7.94%였다. 따라서 1.52%는 안정적인 외부 검증값이 아니다.

### 3-1. 적정 종류 조건부 당량점 후보 모델

센서 입력군 자체의 기여도를 비교한 위 분석과 별도로, 실험 전에 정해지는 **적정 종류**를 모델 선택 조건으로 사용해 당량점 후보 판별 구조를 보강했다. 색상과 열화상 시계열에서 여러 시간 폭의 국소 변화 후보를 만든 뒤, 적정 종류별로 PLS 회귀, 선형·이차 판별분석, RBF 커널 릿지 회귀 중 개발 자료에 적합한 후보 평가기를 적용했다. 현재 주입량, 이론 당량점, 시간, 진행률, 미지 시료 농도와 지시약은 추론 특징에서 제외했다. 표준용액 농도는 1,822개 행에서 모두 0.100 M로 같아 구분 정보가 없으므로 입력에 넣지 않았다.

평가 대상 run은 해당 후보 평가기의 학습과 스케일링에서 제외했다. 이 방식의 12회 결과는 **MAE 0.078 mL, RMSE 0.091 mL, MAPE 0.30%**였고, 12회 모두 상대오차 1% 이내였다. 평가기는 난수를 사용하지 않으므로 세 지정 seed 실행에서 같은 예측이 나왔으며, 이는 seed 강건성이 아니라 결정론적 재실행 확인이다. 선택된 개발 수치는 색 최대 기울기 방식의 MAPE 4.67%, 색·온도 임계값 방식의 5.65%보다 낮았다.

다만 적정 종류별 평가기와 세부 설정은 초기 **1,006,020개 설정**과 추가 집계 **1,024,350개 설정**을 합친 총 **2,030,370개 조합**을 같은 12회 자료에서 비교해 선택했다. 평가 run의 정답도 최종 설정 선택에는 사용되었고 후보 생성 격자도 같은 연구 자료에서 개발했다. 최종 0.295000%는 후보 오라클 0.295000%와 같아 개발 자료에 강하게 맞춰진 값이다. 따라서 0.30%는 **개발 자료 내부에서 사후 선택된 성능**이며, 새로 조제한 미지 시료의 독립 검증 정확도로 사용하지 않는다.

## 4. 주 짝지은 추정량: 색상 APE - 융합 APE

주 짝지은 추정량은 run별 **색상 APE - 융합 APE**이며 단위는 퍼센트포인트(pp)이다. 양수는 융합의 APE가 더 작음을 뜻한다. 평균 개선량은 **0.0275599 pp**였다. 적정 종류를 층으로 유지하고 run을 재표본한 100,000회 bootstrap의 95% 구간은 **[-1.204831, 1.147784] pp**였다. 정확 양측 부호 뒤집기 검정의 p값은 **0.978027**, 정확 양측 부호 검정의 p값은 **0.774414**였다.

융합은 12개 run 중 **7개에서 개선되고 5개에서 악화**되었다. 주 구간은 0을 포함했고 두 정확 검정도 유의하지 않았다. 따라서 현재 자료는 융합의 우수성, 동등성, 보편적 이득, 조건부 이득 또는 외적 타당성을 확립하지 못한다. 이 결과는 이미 선택된 개발 모델을 기준으로 계산한 것이며 모델 선택 과정의 불확실성까지 포함하지는 않는다.

부차적으로 부피 단위 절대오차 개선량의 평균은 **0.0715095 mL**였고, 같은 적정 종류 층화 bootstrap 95% 구간은 **[-0.322663, 0.438838] mL**였다. 이 부차 구간도 0을 포함했다.

## 5. 운영적 종말점-기저 대비도

열화상의 주 기술 지표는 **operational endpoint-to-baseline contrast-to-noise(운영적 종말점-기저 대비도)**로 정의했다. 이 지표는 기기 성능을 측정한 신호대잡음비가 아니다.

- 기저 구간: **0.05 ≤ V/Veq ≤ 0.20**
- 종말점 구간: **0.95 ≤ V/Veq ≤ 1.05**
- 부호를 보존한 대비 신호: **median(종말점) - median(기저)**
- 운영적 잡음: **1.4826 × MAD(기저)**
- 운영적 대비도: **|부호 중앙값 차이| / (1.4826 × MAD)**

이용 가능한 ROI 요약값이 모두 0인 내부 무효 행 **11개**는 제외했다. 주 규칙으로 12개 run 모두에서 대비도를 계산했다. 고정 폭 종말점 구간인 ±0.5 mL, ±1.0 mL, ±2.0 mL는 민감도 분석으로 분리했다. 이 운영적 대비도는 정해진 자료 구간의 온도 대비를 요약할 뿐, 열화상의 예측 우수성을 뜻하지 않는다.

## 6. 운영적 대비도와 융합 개선량의 탐색적 관계

주 구간의 운영적 대비도와 run별 색상 APE - 융합 APE의 Spearman 순위상관계수는 **ρ=-0.223776**이었다. 고정 seed로 100,000회 순열한 탐색적 비보정 검정의 p값은 **0.485015**였다. 이 분석은 탐색적이고 다중 비교 보정을 하지 않았으며, 운영적 대비도가 융합 개선량을 예측한다는 근거가 아니다.

적정 종류별 요약도 각 유형의 run이 3개에 불과한 기술 통계이다. 유형별 유의성 검정은 수행하지 않았고, 특정 반응 유형에서 열화상의 조건부 이득이 있다고 주장하지 않는다.

## 7. 수동 적정 결과의 제한적 비교

수동 적정 12건의 참조 당량 부피와 수동 종말점 부피를 재계산하면 MAE는 0.642 mL, RMSE는 0.750 mL, MAPE는 2.00%이다. 다만 수동 종말점과 당량점 추정 모델의 개발 자료 결과는 판독 방법과 검증 구조가 다르다. 따라서 이 수치를 같은 독립 시료에서 두 방법을 동등하게 검증한 것처럼 비교하거나, 머신러닝이 수동 적정보다 정확하다는 근거로 사용하지 않는다.

## 8. 유량 표현 정정

주사기 단면적과 리드스크류 이동 속도로 계산한 0.962 mL/s는 **이론 유량**이다. 0.99 mL/s는 보고서에서 **실험 당시 주입량 환산에 사용한 설정 유량**으로 구분한다. 두 값의 차이는 약 2.9%이지만, 이를 ‘이론 유량 대비 실측 유량 오차 2.9%’나 ‘평균 보정 정확도’라고 표현하지 않는다. 개별 반복 토출량과 주사기 잔량에 따른 유량 곡선이 현재 근거 자료에 없으므로, 평균·표준편차·정밀도·재현성을 새로 제시하지 않는다. 이 실험의 주입 부피는 실측 피드백이 아니라 펌프 작동 시간과 설정 유량으로 계산한 추정값으로 해석한다.

주사기 잔량과 마찰의 영향을 확인하기 위한 후속 절차는 초기·중간·말기 피스톤 위치에서 물을 반복 토출하고, 위치별 평균·표본 표준편차·CV, 명령 스텝 수에 대한 선형성, 정지 후 추가 토출량과 overshoot를 기록하도록 정리했다. 그러나 이는 빈 기록 양식을 포함한 **검증 계획**이며, 현재 보고할 위치별 측정값은 없다.

## 9. 종말점 근처 펄스 제어 표현

4차 컨설팅에서 제안한 `drop-by-drop` 제어를 반영하여, Windows 프로그램과 Arduino 펌웨어에 **정지 상태 기준색 보정 → 연속 주입 → 접근 감지 → 혼합 대기 → 미세 펄스 주입 → 혼합 대기 → 재판정** 상태기계를 연결했다. 녹화 시작 뒤 펌프가 멈춘 상태에서 초기 기준색과 실시간 모델 입력을 먼저 확보하며, 둘 중 하나라도 확인하지 못하면 펌프를 시작하지 않는다. 이후 모델 점수가 0.20 이상이면 `c` 명령으로 연속 주입을 멈추고 0.50초 동안 안정화한다. 종말점이 아직 확인되지 않으면 원래 주입 명령 `b`와 같은 방향으로 고정된 `STEP 5` 명령을 보낸다. Windows의 주입 방향 설정이 `b`가 아니면 자동 펄스 모드를 시작하지 않는다. Windows는 `STEP ACCEPTED 5`뿐 아니라 펌웨어의 `PUMP STOPPED PULSE_COMPLETE`까지 확인한 뒤 다시 0.50초 동안 혼합과 센서 안정화를 기다린다. 완료 응답을 잃은 펄스는 중복 토출 위험 때문에 자동 재전송하지 않는다. 주입 중 필수 센서·모델 계산이 실패하면 즉시 정지하는 실패-폐쇄 방식을 사용하며, 명목 유량과 별도의 보수적 최대 유량·최대 주입량·최대 연속 구동시간을 안전 상한으로 적용한다. 이 과정을 반복하다가 모델 점수가 0.30 이상일 때 시작된 실제 ROI 색 변화가 0.4초 이상 지속되면 최종 정지한다. 이론 당량점 부피, 최종 진행률, 미지 시료 농도는 제어 조건으로 사용하지 않는다.

**명목·모의 계산:** 펌웨어의 한 스텝 주기는 0.01초이므로 명목상 100 step/s이다. 주입량 환산에 사용한 설정 유량 0.99 mL/s를 적용하면 1스텝은 0.0099 mL, **5 step은 명목 0.0495 mL**로 계산된다. 이 값은 설정 유량과 모터 명령을 이용한 환산값이며, 실측 한 방울 부피가 아니다.

**소프트웨어 검증:** 펌웨어의 `STEP 1~200` 제한, 요청 스텝 완료 후 자동 정지, Windows의 수락·완료 응답 확인, 불확실한 펄스의 중복 재시도 차단, 정지 상태 기준색 보정, 펄스 상태 전환과 CSV 기록은 소스 수준 및 하드웨어 없는 회귀시험으로 확인했다. Arduino UNO 대상 펌웨어 컴파일도 완료했다. 현재 **펄스 제어 근거는 software-only, dry-tested**이다.

**측정값:** 새 펄스 제어에 대한 직접 물 측정값은 없다. 이 기능은 기존 12회 습식 적정에 적용되지 않았으며, 5스텝의 실제 방울·토출량, 주사기 위치별 평균·표준편차·CV·선형성, 정지 지연·overshoot와 정밀도 향상은 검증하지 않았다.

**기존 자료 반사실적 재생:** 기존 12개 CSV를 시간순으로 재생하면 12회 모두 로드되었고 endpoint 양성 행이 있는 10회가 정책 계산에 사용되었다. 이 중 0.4초 연속 양성 조건과 가상 `STEP 5` 정책으로 정지한 자료는 각각 1회뿐이었다. 기존 CSV는 가상 정지 뒤의 혼합과 센서 반응을 포함하지 않으므로, 이 결과는 실제 자동정지 성공률이나 펄스 제어 성능이 아니라 현재 저장 라벨의 지속성에 대한 제한적 점검이다.

## 10. 결론 교체 문안

본 탐구에서는 학교 환경에서 제작한 시린지 펌프, 일반 카메라와 열화상 카메라를 하나의 기록 흐름으로 연결하고, 12회 습식 적정에서 1,822개 시계열 행을 저장했다. 센서 입력군 비교에서는 색상 전용과 색상·열화상 융합의 MAPE가 각각 1.55%와 1.52%로 비슷해, 열화상 추가만으로 보편적인 성능 향상이 나타났다고 보기는 어려웠다. 적정 종류에 따라 후보 판별 구조를 달리한 센서 시계열 모델은 현재 주입량과 미지 시료 농도를 입력하지 않고 MAE 0.078 mL, RMSE 0.091 mL, MAPE 0.30%를 보였으며 12회 모두 상대오차 1% 이내였다. 이 선택된 개발 수치는 같은 자료의 색 최대 기울기 4.67%와 색·온도 임계값 5.65%보다 낮았다. 다만 총 2,030,370개 설정을 같은 12회 결과에서 비교해 고른 값이며 후보 오라클과도 일치하므로, 새 시료의 독립 검증 정확도나 일반적인 향상률로 확대 해석하지 않는다. 이 연구의 핵심 성과는 색상·열화상·계산 주입량을 같은 시간축에 기록하는 비접촉 자동 적정 보조 시스템을 구현하고, 센서 구성과 판정 방법의 개발 자료 수치를 비교했다는 데 있다. 종말점 근처에서는 연속 주입을 멈추고 명목상 0.0495 mL의 5스텝 펄스와 0.50초 대기를 반복하도록 구현했으며, 실제 습식 정밀도 향상은 후속 검증 과제로 남겼다.

# 전국과학전람회 보고서 수정 피드백

기록일: 2026-07-28  
용도: 포스터와 보고서의 최신화 및 심사 피드백 반영 기준

## 전달받은 피드백 원문

1. 이 연구의 목적이 무엇이며 왜 의의가 있는가?

   당량점을 찾아내는데 머신러닝이 어떤 효과가 있는지 의문

2. 온도 측정(열화상 카메라)에서 오차의 범위를 더욱 증가시키는 것이 아닌가?

   열화상 제안 - 변색이 아닌 열을 가지고 측정했을 때 활용방안 제시, 열화상 카메라 활용 방안 제시(머신러닝)

3. 자격루의 분석을 연구 동기에 사용하지 말고 작품내용에서 구현하는 것이 바람직함.

4. 논문과 일지의 차이점

   전람회에서 추구하는 방향 확실히 설정할 것. 오류 내용 및 기기 제작과정 과감히 드러낼 것.

5. 머신러닝과 미지의 농도와의 상관관계 해석 방안 및 실험 데이터 확인 절차 가질 것.

6. 연구제목 변경 -> 비접촉 스마트 적정기로 수정.

   기존방법의 한계 제시 필요.

7. 기존 연구 논문 중 최고상 받은 논문 양식 참고.

추가: 같은 농도 재현성 테스트.

추가 전달사항:

- 같은 농도 재현성 실험 자료는 별도로 존재한다.
- 다만 표준용액 제조 과정의 실수로 제조 배치마다 실제 농도가 달라졌을 가능성이 크다.
- 따라서 파일을 확인하기 전에는 서로 다른 제조 배치의 자료를 같은 농도 반복으로 합치지 않는다.

## 수정 시 지켜야 할 핵심 방향

- 연구의 중심을 단순한 “머신러닝 당량점 예측”이 아니라 **색·열·주입량을 비접촉으로 기록하고 판단을 보조하는 스마트 적정 시스템**으로 재정의한다.
- 머신러닝의 효과는 단일 최종 오차만 제시하지 않고, 색상만·열화상만·색상과 열화상 융합을 비교해 증명한다.
- 열화상이 오차를 줄였다는 결과가 아직 없다면 그렇게 주장하지 않는다. 열화상은 비접촉 보조 신호로 정의하고, 기여도 비교 실험으로 검증한다.
- 자격루는 연구 동기에서 제외하고 시린지 펌프의 정량 주입 원리를 구현한 작품 내용에서 다룬다.
- 보고서는 일지처럼 시간순으로 나열하지 않고, 문제 제기 → 설계 → 실패와 원인 → 개선 → 검증 → 한계의 연구 논리로 구성한다.
- 미지 농도는 예측 당량점 부피에서 계산되는 결과로 명확히 연결하고, 정답 누수 없는 블라인드 확인 절차를 둔다.
- 같은 조건·같은 농도를 반복 측정하여 장치와 모델의 재현성을 별도로 제시한다.
- 재현성 자료는 같은 용액 배치 안의 반복과 다른 제조 배치 사이의 차이를 구분한다. 표정값이 없으면 실제 농도를 새로 만들어 내지 않고 명목 농도와 제조 배치 한계를 함께 밝힌다.
- 기존 수치인 MAPE 1.27%는 같은 12개 개발 자료에서 모델을 선택한 결과임을 유지하고, 독립 정확도처럼 표현하지 않는다.

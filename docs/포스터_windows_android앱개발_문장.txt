Windows 및 Android 앱 개발

Windows 앱은 펌프, 일반 카메라, 열화상 장치를 한 화면에서 제어하고, 적정 중 나타나는 주입량, HSV 색 변화, ROI 온도 변화를 기록하도록 제작하였다. 이 앱에는 이론 당량점과 미지 시료 농도 계산, IUPAC 해리상수 데이터 기반 pKa/pKb 적용, Davies 식을 이용한 활동도 보정, pH 곡선과 지시약 변색 범위 비교, 머신러닝 학습용 CSV 저장 기능을 넣었다.

Android 앱은 Windows 앱의 주요 기능을 스마트폰에서도 사용할 수 있도록 만든 모바일 버전이다. 스마트폰에서 펌프 제어와 데이터 수집을 진행하고, 당량점 후보 분석과 농도 계산 결과를 확인할 수 있도록 하였다.

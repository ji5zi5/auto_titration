# 교사 피드백 반영 보고서 수정 요약

대상 문서: `전국과학전람회_자격루_비접촉스마트자동적정장치_교사피드백반영본.docx`

## 반영 사항

1. 제목을 **자격루에서 착안한 비접촉 스마트 자동 적정 장치**로 변경하였다.
2. 자격루의 일정 흐름·경과 시간·누적량 계량 원리를 기존 장치 설계 절에서 실제 펌프 구조와 연결하였다.
3. 기존 12회 센서 융합 결과를 `비접촉 스마트 적정 장치를 이용한 12회 당량점 부피 추정 결과`로 명시하였다.
4. 결과 순서를 장치 당량점 추정 → 동일 조건 반복성 → 수동 적정 → 비머신러닝·머신러닝 비교 → 센서 구성 비교 → 수동·장치 비교로 재배치하였다.
5. 핵심 데이터 표 7개에 번호와 제목을 붙였다.
6. 수동 적정과 장치의 측정·기록·재분석 특성을 비교하는 표를 기존 비교 절에 추가하였다.
7. 조건별 오차 및 수동·장치 비교 그래프를 가로 막대형으로 바꾸어 기울어진 축 문구를 없앴다.
8. 적정 종류, 판정 방식과 센서 구성을 구분하는 색을 적용하였다.
9. 머신러닝의 핵심 성과를 색 최대 기울기 방식 대비 MAPE 67.4% 감소로 제시하였다.
10. 수동 적정 1.22%와 센서 융합 1.52%의 실제 수치는 변경하지 않고, 수동 적정에 근접한 정확도와 비접촉 자동 기록의 가치를 중심으로 서술하였다.
11. 중복되던 결과 15·16절을 11절 종합 논의와 14절 연구 결과 요약에 통합하였다. 새 절은 추가하지 않았다.
12. 현재 주입량은 머신러닝 입력에서 제외했다는 점을 유지하였다.
13. Android 앱, CSV 25행/s와 자동 정지의 검증 범위를 실제 확인 수준에 맞게 유지하였다.
14. HWP 수식 개체 변환은 후속 편집 단계로 남겼다.

## 검증

`tools/validate_autoresearch_report_revision.py`로 다음 항목을 확인하였다.

- DOCX ZIP 무결성 및 이미지 관계
- 제목과 결과 절 순서
- 표 1~7, 그림 1~31의 연속 번호
- 12회 장치 결과, 수동 결과와 핵심 성능 수치
- 현재 주입량 제외, Android·CSV·자동 정지 범위
- 삭제 대상 중복 절과 금지 표현의 부재

검증 결과는 `.omx/specs/autoresearch-report-revision/result.json`에 기록하였다.

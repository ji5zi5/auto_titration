# 연구 요약

종말점은 지시약 색이나 pH 전극으로 판단한다. 육안은 조명·교반·관찰자에 따라 달라져 재확인이 어렵고, 접촉식 센서는 세척·교정과 오염 관리가 필요하다. 본 탐구는 **색과 겉보기 표면온도를 비접촉으로 측정하고 계산 주입량과 같은 시간축에 기록하는 스마트 적정기**를 제작·검증하였다.

스테퍼 모터와 리드스크류로 100 mL 시린지 펌프를 제작해 일반 카메라와 HIKMICRO Mini2 열화상 카메라를 Windows 프로그램에 연결하였다. 네 가지 산·염기 조합을 세 농도에서 각 1회씩 적정하여 총 12회, 1,822행을 수집하고, 색상 특징 입력군·열화상 특징 입력군·색상과 열화상 특징 입력군을 비교하였다.

이전 센서 입력군 파이프라인에서 현재 주입량을 제외한 개발자료 MAPE는 색상 1.55%, 열화상 3.66%, 색상+열화상 1.52%였다. 융합은 12회 중 7회에서 색상 전용보다 오차가 줄고 5회에서 커졌으며, 평균 개선량의 95% 구간이 0을 포함하여 열화상의 일관된 이득은 확인되지 않았다. 별도로 적정 종류만 사전 조건으로 사용하고 현재 주입량·시간·진행률·미지 농도·이론 당량점을 제외한 센서 시계열 후보 모델은 MAE 0.078 mL, RMSE 0.091 mL, MAPE 0.30%를 보였다. 그러나 총 2,030,370개 설정을 같은 12회 자료에서 사후 비교해 고른 값이고 후보 오라클과도 일치하므로, 새 시료의 독립 검증 정확도가 아닌 개발자료 내부 결과로 해석하였다. 수동 적정 기록의 재계산 MAPE는 2.00%였으나 판독법과 검증 구조가 달라 직접 우열 비교에는 사용하지 않았다. 이후 같은 미지 시료로 지정된 7월 자료 3회에 6월 설정을 고정하여 적용한 결과, 예측 농도 평균은 0.09351 M이고 변동계수는 0.96%였다. 실제 농도는 표정하지 않았으므로 이 결과는 정확도가 아니라 반복성으로만 해석하였다.

# Ⅰ. 탐구 개요

## 1. 탐구 동기

학교의 산·염기 적정은 뷰렛 눈금과 지시약 색을 보고 밸브를 잠그므로 한 방울의 차이, 조명, 관찰자에 따라 달라지고 사후 확인도 어렵다. 카메라는 접촉식 센서와 달리 변화를 연속 기록할 수 있다.

색은 조명·반사·지시약 선택의 영향을 받으므로 열화상 카메라를 보조 센서로 추가하였다. 열화상도 용기 반사와 주변 온도의 영향을 받으므로 오차 감소를 가정하지 않았다. 이에 색·온도·주입량을 기록하고 머신러닝과 열화상의 효과를 구분하는 **비접촉 스마트 적정기**를 탐구 주제로 정하였다.

## 2. 탐구 목적과 탐구 문제

본 탐구의 목적은 **색과 겉보기 표면온도를 비접촉으로 측정하고 계산 주입량과 동기화하는 장치를 제작하여, 당량점 부피 추정·미지 농도 계산·선택형 자동 정지로 연결할 수 있는지 검증하는 것**이다. 동시에 열화상이 당량점 판단에 기여하는 범위와 촬영 조건에 따른 한계를 확인하였다.

1. 학교에서 구할 수 있는 부품으로 일정하게 적정액을 주입하는 시린지 펌프를 제작한다.
2. 일반 영상의 색, 열화상의 겉보기 표면온도와 계산 주입량을 같은 시간축에 저장하고 제작·수집 오류를 개선한다.
3. 제공된 수동 적정 기록, 색 최대 기울기, 색·온도 임계값, 센서 입력군 모델과 적정 종류 조건부 센서 시계열 모델로 각각 당량점 부피를 비교한다.
4. 색상 특징, 열화상 특징, 색상·열화상 특징 입력군을 같은 개발 절차로 비교하여 열화상의 역할과 한계를 판단한다.
5. 정답을 직접 알려 주는 입력을 제외한 추정 부피로 미지 농도를 계산하고, 선택형 자동 정지 구조로 활용 가능성과 검증 한계를 확인한다.

# Ⅱ. 이론적 배경 및 선행 연구

## 1. 당량점과 종말점

**당량점**은 반응식의 계수비에 따라 완전히 반응한 이론적 지점이고, **종말점**은 지시약 색처럼 관찰한 지점이다. 둘은 변색 범위, 산·염기의 세기, 실제 농도와 관찰 시점에 따라 달라진다. 본 탐구는 **이론 당량점 부피**, **색·겉보기 표면온도**, 모델의 **추정 부피**를 구분하고 이론 부피와 추정 부피의 편차를 MAPE로 나타냈다.

## 2. 당량점 부피 계산

시료 농도 (C_s), 시료 부피 (V_s), 시료 반응 가수 (n_s), 적정액 농도 (C_t), 당량점까지의 적정액 부피 (V_t), 적정액 반응 가수 (n_t)는 당량점에서 다음 관계를 만족한다.

\[
C_sV_sn_s=C_tV_tn_t
\]

이론 당량점 부피는 다음과 같다.

\[
V_t=\frac{C_sV_sn_s}{C_tn_t}
\]

산과 염기는 모두 1:1로 반응한다고 두었다. 시료 부피 20.0 mL, 적정액 명목 농도 0.10 M에서 시료 농도 0.10 M, 0.15 M, 0.20 M의 이론 당량점 부피는 각각 20.0 mL, 30.0 mL, 40.0 mL이다. 모델의 추정 부피 \(\hat{V}_t\)로 미지 시료 농도를 계산하였다.

\[
\hat{C}_s=\frac{C_t\hat{V}_tn_t}{V_sn_s}
\]

모델은 센서 시계열과 실험 전에 정해지는 적정 종류로 당량점 후보를 평가하였다. 센서 입력군 비교와 최종 적정 종류 조건부 모델에서는 현재 주입량, 시료 농도, 이론 당량점 부피, 시간, 진행률, 최대 주입량과 전체 실험 길이를 입력에서 제외하였다. 현재 주입량을 넣은 초기 비교는 최종 모델에서 제외하고 참고 결과로만 보존하였다.

## 3. 비접촉 색·열화상 측정의 가능성과 한계

일반 카메라에서는 RGB·HSV 평균값을, 열화상 카메라에서는 **겉보기 표면온도**를 구하였다. 열화상은 용기 재질·반사·촬영 각도·주변 온도의 영향을 받으므로 보조 신호로 사용하고, 세 입력군의 오차로 역할을 판단하였다.

주입량은 펌프 작동 시간×설정 유량 0.99 mL/s로 계산하였다. 이론값은 약 0.962 mL/s였고 두 값의 상대 차이는 약 2.9%였으나, 반복별 토출 시간·부피 원자료가 남아 있지 않아 이 차이를 유량 정확도나 반복성으로 해석하지 않았다. 따라서 0.99 mL/s는 직접 측정 피드백이 아니라 프로그램의 부피 환산 설정값으로 다루었다.

| 신호 | 측정·계산 내용 | 본 탐구에서의 역할 |
|---|---|---|

# Ⅲ. 탐구 과정 및 결과
## 1. 사전 탐구: 무엇을 어떻게 측정할 것인가

### 가. 탐구 질문

이론 당량점, 지시약의 색 변화, 열화상 변화, 계산 주입량과 모델 추정값을 어떤 기준으로 구분하고 기록할 것인가?

### 나. 탐구 방법

기록값을 계산값·관찰값·추정값으로 구분하였다. 이론 당량점 부피는 명목 농도로 계산한 비교 기준, 색 변화는 종말점 관찰값, 열화상 변화는 겉보기 표면온도 변화로 정하고, 펌프 주입량은 작동 시간과 설정 유량으로 계산하였다.

### 다. 탐구 결과

1. 이론 당량점 부피는 명목 농도로 계산한 20.0, 30.0, 40.0 mL로 정하였다.
2. 색 변화는 지시약 종말점을 찾는 주요 관찰값으로 사용하였다.
3. 열화상은 용액 내부의 정확한 온도나 당량점 참값이 아니라 보조 관찰값으로 사용하였다.
4. 주입량은 실측 부피가 아니라 펌프 작동 시간으로 계산한 값으로 기록하였다.
5. 독립 장비로 측정한 실제 당량점이 없으므로 모델 결과는 이론 부피와의 편차로만 비교하였다.

### 라. 소결론

계산값·관찰값·추정값을 구분하여 앱 화면과 CSV 항목을 설계하고 모델 성능의 평가 기준을 정하였다.

## 2. 기본 탐구 1: 비접촉 스마트 적정기 제작

### 나. 시린지 펌프 제작

### 다. Windows 앱 개발 과정

기본 수집기를 예비 시험과 12회 적정에 적용하며 분석 영역, 열화상 변환, 시각 대응, 표시값 구분과 저장 순서의 오류를 확인·수정하였다. 개발자료 수집 뒤에는 자동 정지 기능을 추가하고, 25 fps로 들어오는 프레임을 CSV에 순서대로 보존하는 저장 구조로 개선하였다.

**1) 실제 실험 순서에서 필요한 기능 정리**

적정 중에는 교반·색 관찰·펌프·기록을 함께 조작해야 하므로 여러 화면의 시각과 값을 맞추기 어려웠다. 이에 두 카메라 표시, 실험 조건 입력, 펌프 제어와 색·열화상·주입량의 시간축 저장 기능을 한 앱에 모았다.

**2) 수집기와 대시보드로 역할 나누기**

앱은 카메라·Arduino와 통신하며 CSV를 작성하는 Python 수집기와, 영상·분석 영역·펌프·기록 상태를 조작하는 대시보드로 나누었다.

**3) 일반 카메라의 색 분석과 분석 영역 설정**

화면 전체 평균색에는 책상·조명 반사·실험자의 손이 섞였다. 용액 부분을 사각형으로 지정하여 RGB 평균, HSV의 색조·채도·명도와 시점별 변화량을 계산하였다. 투명 비커의 자동 검출이 불안정하여 실제 12회 적정에서는 일반 영상과 열화상 영상의 영역을 각 화면에서 따로 지정·고정하고, 자동 탐색은 설정 보조로 제한하였다.

**4) Mini2 열화상 자료를 온도값으로 바꾸기**

Mini2의 원시값은 단순 비례식이나 파일별 대응표로 공통 변환할 수 없었다. HIKMICRO 공식 처리 라이브러리와 호환되는 Windows 노트북을 주 실행 환경으로 정하고, 공식 처리 결과로 섭씨 행렬을 만들었다. 분석 영역의 평균·최고·최저값, 온도 분포와 시점별 변화량을 계산하되, 용액 내부 온도가 아닌 용액·용기 영역의 겉보기 표면온도로 기록하였다.

**5) 펌프 제어와 기록 시작·종료 연결**

Arduino 펌웨어의 `a`는 후퇴, `b`는 주입, `c`는 정지 명령이며 기록 시작·종료와 주입·정지를 연결하였다. 실제 토출 부피의 피드백이 없어 작동 시간에 설정 유량 0.99 mL/s를 곱한 값을 계산 주입량으로 표시하고, 펌프 연결·명령·기록 상태를 구분하였다.

**6) 화학 계산과 CSV 구조 추가**

적정 종류, 시료·적정액, 명목 농도, 시료 부피와 지시약을 모든 측정 행에 저장하고 이론 당량점 부피, 해리상수 후보와 지시약 변색 범위를 확인하도록 하였다. CSV에는 기록 시각, 펌프 상태, 계산 주입량, 색상값, 열화상 값, 분석 영역 상태와 두 카메라의 시각 차이를 기록하였다. 최종 모델 입력에서는 현재 주입량, 시료 농도, 이론 당량점, 시간, 진행률, 최대 주입량과 전체 실험 길이를 제외하였다.

**7) 두 카메라의 시각 맞추기**

촬영 간격이 다른 두 카메라를 노트북의 공통 시계로 기록하고, 열화상과 가장 가까운 일반 영상을 짝지어 시각 차이를 CSV에 저장하였다. 실제 12회 자료 1,822행의 평균 절대 시각 차이는 3.66 ms였으며 1,821행은 양호, 1행은 경고였다.

## 4. 심화 탐구 1: 머신러닝을 이용한 당량점 부피와 미지 농도 추정

### 가. 탐구 질문

비접촉으로 얻은 색과 열화상 특징만으로 당량점에 가까운 구간을 찾을 수 있는가? 머신러닝은 단순한 색 변화 또는 색·온도 임계값보다 당량점 부피 오차를 줄이는가? 또한 색상, 열화상, 두 신호의 융합 가운데 어떤 입력이 가장 효과적인가?

### 나. 분석 방법

분석 단위는 연속 프레임이 아니라 **CSV 한 파일에 해당하는 습식 실험 한 회**로 정하였다. 색상과 열화상 시계열에서 여러 시간 폭의 변화 후보를 만든 뒤, 실험 전에 알고 있는 적정 종류에 따라 후보 평가기를 선택하여 실험별 당량점 부피 하나를 산출하였다. 입력은 색상·열화상 센서 특징과 적정 종류뿐이며, 현재 주입량, 시료 농도, 이론 당량점, 시간, 진행률, 최종 주입량, 전체 실험 길이와 지시약은 최종 모델 입력에서 제외하였다.

평가 실험 하나를 후보 평가기의 학습과 스케일링에서 제외하는 outer leave-one-run-out 방식을 사용하였다. 초기 공통 회귀 실험에서는 Ridge, KNN, Random Forest, Extra Trees를 같은 특징 구성에서 비교하였다. 이후 센서 변화 후보를 직접 평가하는 단계에서는 PLS, 선형 판별분석(LDA), 이차 판별분석(QDA), prototype, pairwise ridge, RBF 커널 릿지, 2차 커널 릿지, RBF SVR의 여덟 알고리즘 계열과 후보 점수의 정규화·집계 방법을 탐색하였다. 초기 공통 회귀와 최종 후보 평가 방식은 특징 표현과 탐색 범위가 다르므로 두 단계의 오차를 같은 조건의 순위처럼 직접 비교하지 않았다. 최종적으로 강산-강염기는 PLS, 강산-약염기는 RBF 커널 릿지, 약산-강염기는 LDA, 약산-약염기는 QDA가 선택되었다.

다만 후보 생성과 최종 설정 선택에는 같은 12회 자료의 정답이 사용되었다. 초기 1,006,020개와 추가 1,024,350개를 합친 **2,030,370개 설정**을 같은 자료에서 비교했고, 선택 결과의 MAPE가 후보 오라클과 같았다. 따라서 아래 결과는 평가 실험을 평가기 학습에서 제외한 값이지만, 설정 선택 편향이 남아 있는 **사후 개발자료 결과**이다. 새로 조제한 미지 시료에서 확인한 독립 정확도가 아니다.

센서 자체의 기여도는 현재 주입량을 제외한 색상 전용, 열화상 전용, 색상+열화상 모델을 별도로 비교하였다. 또한 같은 12개 CSV에 색 최대 기울기와 색·온도 임계값 규칙을 적용하였다. 수동 적정 기록은 최종 원자료 파일의 12개 값을 재계산하되, 자동 방식과 판독법·검증 구조가 달라 참고 비교로만 사용하였다.

**그림 11.** 네 적정 종류에서 선택된 평가기와 종류별 개발자료 MAPE. 종류마다 신호 변화 형태가 달라 서로 다른 평가기가 선택되었다.

평가에는 평균 절대편차(MAE), 평균 제곱근편차(RMSE), 평균 절대백분율편차(MAPE)를 사용하였다.

\[
MAE=\frac{1}{N}\sum_{i=1}^{N}|V_i-\hat{V}_i|
\]

\[
RMSE=\sqrt{\frac{1}{N}\sum_{i=1}^{N}(V_i-\hat{V}_i)^2}
\]

\[
MAPE=\frac{100}{N}\sum_{i=1}^{N}\left|\frac{V_i-\hat{V}_i}{V_i}\right|
\]

여기서 \(V_i\)는 이론 당량점 부피, \(\hat{V}_i\)는 모델의 추정 부피이다.

### 사. 미지 농도 계산과 자료 확인 절차

모델이 정한 당량점 부피 \(\hat{V}_t\)를 앞의 농도식에 대입하여 미지 농도 \(\hat{C}_s\)를 계산한다. 즉 머신러닝은 농도를 직접 맞히는 것이 아니라 당량점 부피를 찾고, 농도는 반응식으로 계산한다.

1. 표준용액을 표정하거나 독립 기준으로 실제 농도를 확인한다.
2. 평가할 시료의 농도와 이론 당량점 부피를 숨긴다.
3. CSV의 시간 순서, 주입량 증가, 분석 영역, 열화상 0값·결측과 카메라 시간 차이를 검사한다.
4. 현재 주입량, 시료 농도, 이론 부피, 정답까지의 거리와 진행률이 모델 특징에 없는지 확인한다.
5. 고정한 색상·열화상·융합 모델로 각각 당량점 부피를 추정한다.
6. 추정 부피로 농도를 계산한 뒤 독립 기준 농도와 비교한다.
7. 부피 오차와 농도 오차, 실패한 실험을 함께 기록한다.

별도로 7월에 같은 미지 시료를 사용했다고 지정한 세 실험에는 6월 개발자료에서 정한 모델과 집계 설정을 고정하여 적용하였다. 예측 농도는 0.09248, 0.09411, 0.09394 M였고 평균 0.09351 M, 표본 표준편차 0.00090 M, 변동계수 0.96%였다. 실제 농도는 표정하지 않았으므로 이 값으로 정확도나 오차율을 계산하지 않고, 같은 시료에 대한 반복성만 평가하였다.

## 5. 심화 탐구 2: 종말점 근처 미세 주입과 선택형 자동 정지

### 가. 탐구 질문

이론 당량점 부피를 직접 정지 기준으로 사용하지 않으면서, 종말점 접근 뒤 연속 주입을 미세 주입으로 바꾸고 모델 판단과 실제 색 변화로 펌프를 정지할 수 있는가?

### 나. 구현 방법

4차 서면컨설팅에서는 연속 주입만 유지하면 종말점 부근에서 과주입될 수 있으므로 `drop-by-drop`에 가까운 제어가 필요하다는 의견이 제시되었다. 이에 실제 적정 12회를 마친 뒤 Windows 프로그램과 Arduino 펌웨어에 사용자가 선택할 때만 작동하는 미세 펄스 주입 기능을 추가하였다.

1. 녹화를 시작하되 펌프는 정지 상태로 유지하고 약 1초 동안 일반 영상 ROI의 기준색과 실시간 제어 모델 입력을 확인한다.
2. 기준색이나 필수 모델 입력을 정해진 시간 안에 확보하지 못하면 펌프를 시작하지 않고 기록을 종료한다.
3. 준비가 확인되면 펌웨어 구동시간 제한 `G <ms>`와 주입 방향 명령을 보낸다. Windows는 펌웨어가 같은 시간 한도와 방향을 응답했을 때만 연속 주입을 시작한 것으로 인정하며, 불일치하거나 필수 센서·모델 계산이 실패하면 정지 명령을 보내는 실패-폐쇄 방식으로 처리한다.
4. 실시간 제어 모델 점수가 0.20 이상이면 종말점 접근 구간으로 판단하고 `c` 명령으로 연속 주입을 멈춘 뒤 0.50초 동안 혼합을 기다린다.
5. 종말점이 아직 확인되지 않으면 Arduino에 `STEP 5` 명령을 보내 5스텝만 움직인다. 현재 장치 배선에서 주입 방향은 `b`, 되감기 방향은 `a`이므로 펌웨어의 펄스 방향도 `b`로 맞추었다. Windows는 연속 주입 방향과 펌웨어의 펄스 방향이 일치하지 않으면 자동 펄스 모드를 시작하지 않는다.
6. Windows는 `STEP ACCEPTED 5`와 `PUMP STOPPED PULSE_COMPLETE`를 모두 확인한다. 완료 응답 대기가 막혀도 별도의 비상정지 경로로 `c`를 먼저 보낼 수 있으며, 응답이 불확실하면 중복 토출을 막기 위해 자동 재전송하지 않고 정지 상태로 끝낸다.
7. 완료 응답 뒤 다시 0.50초 동안 혼합과 센서 안정화를 기다리고, 종말점이 확인되지 않으면 5~7단계를 반복한다.
8. 모델 점수가 0.30 이상일 때 시작된 ROI 색 변화가 0.4초 이상 지속되면 최종 `c` 명령을 보내고 정지 시각과 계산 주입량을 CSV에 기록한다.
9. 수동 밀기·되감기와 자동정지를 끈 일반 녹화는 `c` 정지 명령 전까지 계속 동작한다. 자동정지를 켠 경우에만 보수적 최대 유량, 비상 주입 상한 100 mL, `G <ms>` 펌웨어 제한 최대 120초와 `STEP 1~200` 범위를 적용한다. 중복 시작은 제한시간을 갱신하지 않고, 같은 녹화 세션에서 정지 후 재시작해도 앞서 계산된 주입량을 최대부피에서 차감한다. CSV 시작·종료 또는 센서 큐 정리 중에는 동시에 들어온 주입·후퇴 요청을 대기 후 실행하지 않고 거부한다.

펌웨어의 한 스텝 주기는 HIGH 5000 마이크로초와 LOW 5000 마이크로초를 합한 0.01초이므로 명목상 초당 100스텝이다. 설정 유량 0.99 mL/s를 적용하면 1스텝은 0.0099 mL, 기본 5스텝 펄스는 0.0495 mL로 환산되어 CSV 계산 주입량에 더해진다. 최대량 안전 판단에는 별도 상한 0.0105 mL/step을 적용해 펄스당 0.0525 mL를 보수적으로 예약한다. 두 값 모두 실제 한 방울 또는 실측 토출량이 아니다.

**그림 23.** 정지 상태에서 기준색과 제어 모델을 확인한 뒤 연속 주입하고, 접근 감지 후 5스텝 미세 주입·완료 응답 확인·0.50초 대기를 반복하는 과정.

### 다. 구현 결과

기존 `a`, `b`, `c` 명령을 유지하면서 `STEP 1~200` 명령을 추가하였다. 펌웨어는 요청한 스텝을 수행한 뒤 모터 드라이버를 자동 비활성화하고, Windows 프로그램은 수락과 완료 응답을 모두 확인한다. 통신 결과가 불확실한 펄스는 자동 재전송하지 않으므로 이 구조는 ‘정확히 한 번 전송’이 아니라 **중복 토출을 피하는 at-most-once 처리와 명시적 불확실성 기록**이다. 또한 응답 대기 중 비상정지 선점, 최종 취소 검사와 방향 바이트의 원자적 중재, 방향·구동시간 응답 일치, 중복 시작 차단, 녹화 세션 누적부피 한도 유지, CSV 전환과 펌프 시작의 경쟁 차단, 종료 요청의 진행 중 시작 취소, 소유 토큰과 세션 번호 래치를 이용한 자동·수동 정지 중첩 차단, 이전 세션 지연 콜백의 새 세션 간섭 차단, 필수 센서 오류의 덮어쓰기 방지를 건식 회귀시험으로 확인하였다. 부호나 공백이 섞인 안전 한도 명령도 정수 변환 전에 펌웨어에서 거부한다. 연속 구동 시간, 펄스 횟수·총 스텝 수·명목상 펄스 부피와 정지 원인은 CSV에 구분해 기록한다. 펌웨어 계약, 상태 전환, 시리얼 응답과 CSV 기록은 하드웨어 없는 단위·통합시험으로 확인했으며 Arduino Uno 대상 컴파일도 통과하였다.

자동 정지에 사용하는 실시간 분류기는 실험 전체 기록에서 부피 하나를 사후 선택한 앞 절의 0.30% 모델과 별개이다. 실제 12회 적정은 사람이 정지했으며 새 미세 주입 기능으로 반복하지 않았다. 따라서 0.0495 mL는 실측 방울 부피가 아니고, 실제 정지 부피·명령 지연·과주입량·정밀도 향상은 아직 확인하지 못하였다.

기존 12개 CSV를 시간순으로 재생한 반사실적 점검에서는 12회 모두 로드되었고 endpoint 양성 행이 있는 10회가 정책 계산에 사용되었다. 그중 0.4초 연속 양성과 가상 `STEP 5` 정책으로 정지한 자료는 1회뿐이었다. 저장된 라벨은 가상 펄스 뒤 새로 생길 혼합·센서 반응을 포함하지 않으므로, 이는 실제 자동 정지 성공률이 아니라 현재 라벨 지속성의 제한적 점검이다.

### 라. 소결론

연속 주입을 종말점 접근 뒤 5스텝 미세 주입으로 전환하고, 응답 확인·혼합 대기·센서 재판정을 반복하는 선택형 자동 정지 구조를 구현하였다. 소프트웨어와 펌웨어 수준에서는 drop-by-drop에 가까운 명령이 가능하지만, 실제 방울 부피와 정지 정확성은 습식 반복시험 전까지 검증된 성능으로 제시하지 않는다.

# Ⅳ. 종합 논의

## 1. 탐구를 통해 확인한 점

제작한 시린지 펌프와 일반·열화상 카메라를 산·염기 적정에서 함께 구동하여 색, 겉보기 표면온도와 계산 주입량을 하나의 CSV에 기록하였다. 여기서 ‘비접촉’은 시료 채취나 적정액 주입이 아닌 관찰 신호의 측정 방식을 뜻한다. 적정 종류마다 변화 곡선이 달라 모든 조건에 하나의 단순 임계값을 적용하기 어려웠다.

이전 센서 입력군 파이프라인의 개발자료 MAPE는 색상 1.55%, 열화상 3.66%, 색상+열화상 1.52%였다. 융합은 7회에서 색상 전용보다 오차가 줄고 5회에서 커졌으며, 평균 APE 개선량의 95% 구간은 0을 포함하였다. 따라서 열화상을 모든 적정에서 정확도를 높이는 센서로 단정하지 않고 탐색적 보조 신호로 재분류하였다.

적정 종류 조건부 센서 시계열 모델의 선택된 개발자료 결과는 MAE 0.078 mL, RMSE 0.091 mL, MAPE 0.30%였고 12회 모두 1% 이내였다. 그러나 평가 run의 정답이 평가기 학습에는 들어가지 않았더라도 최종 설정 선택에는 같은 12회 정답을 사용했고, 총 2,030,370개 설정 중 고른 결과가 후보 오라클과 일치했다. 이 때문에 0.30%는 실시간 자동정지 성능이나 새 시료 일반화 정확도가 아니라, 전체 기록을 사후 분석한 개발자료 최저값이다.

수동 제공 기록의 재계산 MAPE는 2.00%, 색 최대 기울기는 4.67%, 색·온도 임계값은 5.65%였다. 수동 기록과 모델은 판독법·검증 구조가 달라 직접 우열을 주장하지 않았다. 6월 12조건은 각 종류·농도 조합이 한 번뿐이어서 조건별 반복성과 새로운 조제 배치에 대한 일반화를 확인하지 못하였다. 다만 별도 7월 동일 미지 시료 3회에 6월 설정을 고정해 적용했을 때 예측 농도의 변동계수는 0.96%였다. 실제 농도는 표정하지 않아 정확도는 판단하지 않았다.

# Ⅴ. 결론 및 활용 방안

## 1. 결론

본 탐구에서는 학교 환경에서 제작한 시린지 펌프, 일반 카메라와 열화상 카메라를 하나의 기록 흐름으로 연결하고, 12회 습식 적정에서 1,822개 시계열 행을 저장하였다. 이전 센서 입력군 파이프라인에서 색상 전용과 색상·열화상 융합 모델의 개발자료 MAPE는 각각 1.55%와 1.52%로 비슷했고, 열화상 추가 후 오차는 7회 감소하고 5회 증가하여 일관된 향상을 확인하지 못하였다. 이후 구성한 현재 적정 종류 조건부 센서 시계열 모델은 현재 주입량·시간·진행률·미지 농도·이론 당량점을 입력하지 않고 MAE 0.078 mL, RMSE 0.091 mL, MAPE 0.30%를 보였다. 다만 2,030,370개 설정을 같은 12회 자료에서 사후 선택했고 후보 오라클과 일치하므로, 이 값은 새 시료의 독립 정확도가 아닌 개발자료 내부 결과이다. 별도 7월 동일 미지 시료 3회에는 6월 설정을 고정하여 적용했고 예측 농도의 변동계수는 0.96%였으나, 실제 농도를 표정하지 않아 정확도는 평가하지 않았다. 종말점 근처에서는 연속 주입을 멈추고 명목상 0.0495 mL의 5스텝 펄스와 0.50초 대기를 반복하도록 구현했지만, 실제 펄스 토출량과 습식 자동정지 정확성은 검증하지 않았다. 본 작품의 확인된 성과는 적정액 주입, 비접촉 관찰, 동기화 기록, 사후 당량점 추정과 안전한 제어 명령을 하나의 시제품으로 통합한 데 있으며, 실제 유량 반복성·표정한 용액의 조건별 반복 실험·새 시료 정확도 검증은 후속 과제로 남는다.

## 2. 활용 방안

1. **학교 적정 기록**: 색 변화 전후의 색·열화상·주입량을 다시 확인한다.
2. **지시약 비교**: 지시약별 색 변화 시점과 이론 당량점의 차이를 비교한다.
3. **센서 융합**: 같은 절차로 세 입력군의 기여도와 적용 범위를 비교한다.
4. **자동 제어 교육**: 측정·저장·머신러닝 판단·모터 제어의 연결을 학습한다.

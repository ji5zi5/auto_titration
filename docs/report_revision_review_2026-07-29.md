# 전국과학전람회 보고서 1차 수정 검토

검토 대상: `전국과학전람회_비접촉스마트적정기_그래프삽입_1차수정본.docx`

## 이번 수정본에 반영한 내용

1. 표지 제목을 **비접촉 스마트 적정기**로 변경하였다.
2. 자격루 내용은 연구 동기의 중심에서 빼고, 일정 흐름·시간·누적량·시점 알림을 실제 장치에 어떻게 대응했는지 장치 설계 절로 옮겼다.
3. 사람이 정지한 12회 실험을 자동 정지 검증으로 오해하지 않도록 결과 절 제목과 표의 표현을 **적정 데이터 기반 센서 융합 모델 추정**으로 바꾸었다.
4. 12회 모델 결과표는 예측값과 절대오차를 소수 셋째 자리까지 표시하여, 표에 보이는 수치와 상대오차의 관계를 확인하기 쉽게 만들었다.
5. 수동·비머신러닝·머신러닝 비교표에 수동 적정 결과(MAE 0.367 mL, RMSE 0.406 mL, MAPE 1.22%)를 추가하였다.
6. 기존 결과 그림 6개를 검산된 새 그래프로 교체하고, 조건별 오차와 CSV 저장 처리 시험 그래프 2개를 추가하였다.
7. 그림 번호 중복을 없애고 본문 순서대로 그림 1~31로 다시 번호를 붙였다.
8. 현재 주입량을 제외한 센서 전용 모델 결과만 사용하였다. 과거 1.27% 모델은 사용하지 않았다.
9. Android 앱은 확장 시제품이며 12회 습식 실험과 머신러닝 평가에 사용하지 않았음을 명시하였다.
10. 25.0행/s 결과는 새 습식 실험이 아니라 0.04초 간격 시험 입력을 사용한 CSV 처리 경로 시험임을 명시하였다.
11. 정확한 원수치로 다시 계산하여 비머신러닝 색 최대 기울기 대비 융합 모델의 감소율을 MAPE 67.4%, MAE 59.7%로 고쳤다.

## 제출 전에 반드시 손볼 부분

### 1. 결과 절이 지나치게 길고 같은 결론이 반복됨

Ⅲ장의 11절, 14절, 15절, 16절은 다음 내용이 반복된다.

- 수동 적정 1.22%와 센서 융합 모델 1.52%는 비슷한 수준이다.
- 머신러닝은 비머신러닝보다 오차가 작다.
- 열화상 융합은 색상 단독보다 0.03%p만 낮다.
- 표정·반복·블라인드 검증이 더 필요하다.

권장 구조:

- 11. 종합 논의
  - 머신러닝의 효과
  - 열화상의 역할
  - 수동 적정과의 관계
  - 오차와 한계

새 절은 추가하지 않는다. 현재 14~16절의 새 정보만 11절에 옮기고, 중복되는 14~16절은 삭제하거나 기존 분량을 크게 줄이는 편이 좋다.

### 2. 기존 ‘연구 결과의 요약’을 결론처럼 정리할 필요가 있음

새 결론 절을 만들지 않고 현재 `14. 연구 결과의 요약`을 결론 역할을 하도록 압축한다. 다음 네 문장을 중심으로 정리하면 된다.

1. 비접촉 방식으로 색상·열화상·펌프 작동 정보를 같은 시간축에 기록하였다.
2. 센서 융합 모델은 MAPE 1.52%로 비머신러닝 기준선 4.67%, 5.65%보다 낮았다.
3. 수동 적정 1.22%보다 정확하다고 할 수는 없지만 자동 기록과 재분석 가능성을 확보하였다.
4. 열화상 융합의 개선 폭은 0.03%p로 작아 후속 반복 검증이 필요하다.

### 3. 표 번호와 표 제목이 없음

현재 Word 표가 13개 이상 들어 있지만 `표 1`, `표 2`와 같은 번호가 없다. 결과표는 최소한 다음처럼 번호를 붙여야 한다.

- 표 1. 적정 종류와 실험 조건
- 표 2. 적정 종류별 센서 융합 모델 성능
- 표 3. 12회 당량점 부피 추정 결과
- 표 4. 수동 적정 결과
- 표 5. 수동·비머신러닝·머신러닝 성능 비교
- 표 6. 동일 용액 반복 측정 결과

### 4. 수식이 Word 수식이 아니라 일반 문자열임

`{... over ...}`, `sqrt`, `BIGG`가 그대로 보여 완성도가 낮다. 다음 수식은 Word 수식 입력기로 다시 작성해야 한다.

- 당량 관계식과 농도 계산식
- 약산·약염기 평형식
- 유량식
- MAE, RMSE, MAPE

### 5. 같은 표와 같은 사진이 반복됨

- 적정 종류별 모델 성능표가 결과 3절과 6절에서 반복된다.
- 전체 장치 사진, 펌프 사진과 앱 화면이 뒤쪽 요약·기대효과에서 다시 사용된다.
- 결과 본문에서는 같은 사진을 다시 넣기보다 앞 그림 번호를 인용하는 편이 낫다.

중복 그림을 줄이면 현재 31개인 그림 수와 문서 용량을 함께 줄일 수 있다.

### 6. 12회 결과는 개발자료이며 독립 최종검증이 아님

실험 파일 단위 leave-one-out으로 프레임 누수는 막았지만, 모델 종류와 설정을 같은 12회 자료에서 선택하였다. 따라서 **독립된 미지 시료에서 1.52%가 재현되었다**고 쓰면 안 된다. 현재 표현처럼 개발자료 내부 비교 결과라고 한정해야 한다.

### 7. 조건별 반복이 부족함

네 반응계×세 농도는 각 조건당 1회이다. 현재 반복성 자료 3개는 별도의 동일 용액 반복 결과이므로, 12개 조건 각각의 재현성을 증명하지는 못한다. 후속 실험에서는 조제 배치와 날짜를 달리해 조건별 최소 3회 반복하는 것이 우선이다.

### 8. 반복성 자료의 기준 농도가 불명확함

0.0824 M, 0.0851 M, 0.0889 M는 실제 표정 농도가 없으므로 정확도 자료로 쓰지 말고 반복성 자료로만 써야 한다. 가능하면 어떤 시료·적정액·지시약·계산식으로 얻은 값인지 표 아래에 한 줄로 명시해야 한다.

### 9. 자동 정지의 실제 습식 검증이 없음

소프트웨어 시험은 통과했지만 실제 12회 적정은 사람이 정지하였다. 따라서 “자동 정지 기능을 구현하였다”까지는 쓸 수 있으나 “자동 정지 정확도를 검증하였다”라고 쓰면 안 된다. 실제 정지 지연, 잔여 방울과 과주입량을 별도 실험해야 한다.

### 10. 펌프 주입량이 직접 측정값이 아님

주입량은 0.99 mL/s와 작동 시간의 곱이다. 최종 제출 전에 가능하면 전자저울을 이용한 질량법으로 일정 시간 토출량을 여러 번 측정하고 평균·표준편차를 추가하는 것이 좋다.

## 본문에 남길 핵심 그래프

우선순위가 높은 그래프는 다음 여섯 개이다.

1. 12회 이론값과 센서 융합 모델 추정값
2. 12회 조건별 절대 상대오차
3. 수동·비머신러닝·머신러닝 MAPE 비교
4. 색상·열화상·융합 입력 구성 비교
5. 동일 용액 3회 반복 측정
6. CSV 저장 처리 경로 개선

지면이 부족하면 수동·센서 융합 조건별 비교와 적정 종류별 융합 모델 MAPE는 부록으로 보내고, MAE·RMSE 전체 비교 그래프는 표로 대체할 수 있다.

## 현재 보고서의 핵심 해석

이 연구의 가장 강한 결론은 “머신러닝이 수동 적정보다 정확하다”가 아니다. **같은 12회 원자료에서 고정 규칙 방식의 MAPE 4.67%, 5.65%를 센서 융합 머신러닝으로 1.52%까지 낮추었고, 수동 적정 1.22%와 비슷한 수준에서 판정 근거를 자동 기록하고 다시 분석할 수 있게 만들었다**는 것이다.

열화상은 단독 MAPE가 3.66%이고 융합 개선 폭도 0.03%p이므로, 정확도를 크게 높인 핵심 센서라고 단정하면 안 된다. 색상과 다른 신호를 보존하고 실패 원인을 확인하는 보조 센서로 설명하는 것이 현재 자료에 가장 잘 맞는다.

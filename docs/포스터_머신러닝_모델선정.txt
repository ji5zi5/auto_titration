머신러닝 모델 선정 과정

가. 학습 목표
색 변화, 온도 변화, 주입량 데이터를 이용하여 한 번의 적정 실험에서 당량점에 가까운 주입 부피를 예측하도록 모델을 만들었다. 예측된 당량점 부피는 이후 미지 시료 농도 계산에 사용한다.

나. 입력 데이터
모델에는 실험 중 실제로 얻을 수 있는 값만 사용하였다. 주입량, HSV 색상값, ROI 온도값, 온도 분위값, 색 변화량, 온도 변화량, 적정 종류, 표준용액 정보 등을 사용하였다. 이론 당량점, 정답과의 거리, 최종 주입량으로 계산한 진행률은 예측 입력에서 제외하였다.

다. 모델 비교 방법
전체 12개 실험 데이터를 이용해 여러 방식의 모델을 비교하였다. 단순히 실험 전체 평균값으로 예측하는 회귀 모델, 센서 변화 후보를 보정하는 모델, 프레임별로 당량점 근처 여부를 분류하는 모델을 비교하였다.

비교 결과	평균 상대오차
실험 전체 요약 회귀	16.08%
프레임별 남은 부피 회귀	16.64%
센서 후보 보정 회귀	19.29%
프레임별 당량점 근처 분류	6.03%
적정 종류별 최적 모델 선택	1.27%

라. 최종 선정 방식
최종적으로는 적정 종류별로 모델을 나누는 방식을 선택하였다. 실제 실험에서도 강산-강염기, 강산-약염기, 약산-강염기, 약산-약염기 중 어떤 적정인지 알고 시작하므로, 하나의 통합 모델보다 적정 종류별 모델을 사용하는 것이 더 현실적이다.

마. 최종 모델
강산-강염기	Extra Trees 분류 모델	평균 상대오차 0.47%
강산-약염기	Extra Trees 분류 모델	평균 상대오차 0.67%
약산-강염기	Random Forest 분류 모델	평균 상대오차 3.49%
약산-약염기	Extra Trees 분류 모델	평균 상대오차 0.45%
전체	적정 종류별 모델 조합	MAE 0.392 mL, RMSE 0.685 mL, 평균 상대오차 1.27%

바. 선정 이유
프레임별 분류 모델은 각 프레임이 당량점 근처인지 판단한 뒤, 점수가 높은 프레임들의 주입량을 모아 최종 당량점 부피를 계산한다. 이 방식은 색 변화와 온도 변화가 한 순간에만 나타나지 않고 구간 형태로 나타나는 적정 데이터에 잘 맞았다.

사. 포스터용 요약 문장
여러 회귀 모델과 분류 모델을 비교한 결과, 프레임별로 당량점 근처 여부를 판단한 뒤 주입량을 모아 예측하는 방식이 가장 안정적이었다. 최종적으로 적정 종류별 모델을 사용하였고, 전체 12개 실험에서 평균 상대오차 1.27%, MAE 0.392 mL로 당량점 부피를 예측하였다.

아. 해석 및 한계
강산-강염기, 강산-약염기, 약산-약염기 조건은 1% 안팎의 오차를 보였고, 약산-강염기 조건은 0.20 M 실험에서 오차가 커 평균 오차가 3.49%로 나타났다. 현재 결과는 12개 실험 데이터에서 얻은 모델 선정 결과이므로, 반복 실험을 늘리면 모델 신뢰도를 더 높일 수 있다.

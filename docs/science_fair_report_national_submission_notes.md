## 0. 기존 자동 생성본의 상태

- 개인정보 입력 대기본: `docs/제72회_작품설명서_자동생성검토본.hwpx`
- 개인정보 삭제 검토본: `docs/제72회_작품설명서_개인정보삭제_자동생성검토본.hwpx`
- 사용한 공식 원본: `docs/official_forms/제72회_전국과학전람회_각종서식.hwpx`
- 재생성 명령: `.venv/bin/python tools/build_national_report_hwpx.py`

2026-08-06 최신 원고는 그림 16개, 표 15개이다. 근거가 확인되지 않은 동일 용액 3회 반복 결과는 삭제하고, 적정 종류 조건부 센서 시계열 모델의 사후 개발자료 결과, 열화상 기여도, 4차 컨설팅에 따른 미세 펄스 제어와 검증 한계를 반영하였다. 이 환경에는 한글 렌더러가 없으므로 **한글에서 직접 열어 다시 저장하고**, 글자 넘침·표 잘림·쪽 번호·목차 쪽수와 표지·목차 제외 30쪽 이내 여부를 확인한다.

핵심 수치와 표현은 다음으로 통일한다.

- 실제 습식 실험: 12회, 1,822행, 각 종류·농도 조건 1회
- 센서 입력군 개발 MAPE: 색상 1.55%, 열화상 3.66%, 색상+열화상 1.52%
- 적정 종류 조건부 센서 시계열 모델: MAE 0.078 mL, RMSE 0.091 mL, MAPE 0.30%
- 0.30%는 2,030,370개 설정을 같은 12회 자료에서 사후 선택한 값이며 독립 정확도가 아님
- 수동 제공 기록 재계산: MAE 0.642 mL, RMSE 0.750 mL, MAPE 2.00%
- 열화상 융합: 개선 7회, 악화 5회. 평균 APE 개선량 95% 구간이 0을 포함함
- 자동 정지: 실시간 분류기와 0.30% 사후 모델은 별개이며, 5스텝 명목 0.0495 mL 제어는 건식 시험만 완료함

## 2. 공식 작품설명서 규격

- 공식 서식 6의 작품설명서 표지를 사용한다.
- 한글 **HWPX** 파일로 제출한다.
- A4, 좌철 제본용으로 편집한다.
- 표지와 목차를 제외한 작품설명서는 **30쪽 이내**로 맞춘다.
- 여백: 좌·우 20 mm, 위·아래 15 mm, 머리말·꼬리말 10 mm.
- 본문: 휴먼명조 11 pt, 줄간격 160%, 자간 0, 장평 100.
- 쪽 번호: 하단 중앙.
- 목차에는 실제 쪽 번호를 반드시 기재한다.
- 그림과 사진은 문서에 포함하고 ‘일반 글자처럼 취급’을 적용한다. 외부 파일 경로에 연결하지 않는다.
- 작품의 동기, 목적, 내용, 과정, 결론, 전망·활용성과 **생성형 AI 활용 여부·목적·범위**를 체계적으로 기술한다.

## 4. 아직 실제 자료를 넣어야 하는 그림

- 실제 적정 중 Windows 대시보드: visible ROI, thermal ROI, 펌프 상태와 저장 행 수가 함께 보이는 화면

국립중앙과학관 전람회 통합검색과 RISS 검색 화면은 2026-07-14에 실제 웹사이트에서 다시 캡처해 그림 2와 그림 3으로 반영하였다. 대시보드 화면은 현재 보존된 실제 캡처가 없어 삽입 표시를 유지한다. 임의 합성 화면이나 장치를 연결하지 않은 예시 화면으로 대체하지 않는다.

그림 6은 다음 조건을 한 화면에서 충족한 뒤 캡처한다.

1. 일반 카메라와 Mini2 영상이 모두 실제 비커를 표시함
2. visible ROI와 thermal ROI가 각각 용액 영역에 고정됨
3. 펌프 상태가 주입 중으로 표시되고 계산 주입량이 증가함
4. 녹화가 시작되어 저장 행 수가 50행 이상 표시됨
5. 개인 파일 경로, 사용자 이름과 알림창이 화면에 남지 않음

## 5. 추가 원자료가 있을 때만 보강할 내용

### 펌프 물 토출 점검

현재 저장소에는 앱에서 사용한 0.99 mL/s 설정값은 남아 있지만, 물 토출 시험의 개별 측정값은 확인되지 않는다. 위치별 보정 도구와 빈 입력 양식은 구현했지만 측정 결과가 아니다. 당시 기록이 실제로 있다면 다음 표를 사전 탐구에 추가한다.

| 회차 | 작동 시간(s) | 토출 질량 또는 부피 | 환산 유량(mL/s) | 측정 도구 |
|---:|---:|---:|---:|---|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |
| 4 |  |  |  |  |
| 5 |  |  |  |  |

개별 기록이 없으면 본문의 현재 표현처럼 0.99 mL/s를 **실험 당시 설정 유량**으로 두고, 평균·표준편차 또는 정밀 보정 성능을 새로 만들지 않는다.

### 실제 당량점 기준

pH 전극, 표정된 용액, 전위차법 등으로 새로 측정한 독립 기준값이 있을 때만 ‘실제 당량점 정확도’를 추가한다. 현재 20.0, 30.0, 40.0 mL는 명목 농도로 계산한 이론 부피이므로 다음 용어를 유지한다.

- 명목 농도로 계산한 이론 당량점 부피
- 센서 자료로 추정한 부피
- 이론 부피와 추정 부피의 편차
- 같은 12회 자료에서 분석 방법을 고른 개발 결과

## 6. 30쪽 조판 권장 배분

이전 PDF·DOCX의 쪽수는 개정 전 원고를 기준으로 한 값이므로 더 이상 제출 분량의 근거로 사용하지 않는다. 앱 개발 과정을 보강한 개정 원고는 약 2.5만 자이며, 최종 HWPX의 글꼴 폭·수식·표 나눔에 따라 쪽수가 달라질 수 있으므로 실제 조판 뒤 다시 확인한다.

| 구간 | 권장 쪽수 |
|---|---:|
| 1. 탐구 개요 | 3쪽 |
| 2. 이론적 배경·선행연구 | 4쪽 |
| 3. 사전·기본·심화 탐구 | 17쪽 |
| 4. 논의·한계 | 2쪽 |
| 5. 결론·활용 | 2쪽 |
| 6. 생성형 AI 활용 | 1쪽 |
| 7. 참고문헌 | 1쪽 |
| **합계** | **30쪽** |

결과 페이지는 큰 그림 또는 표 하나와 해석을 같은 면에 배치한다. 12회 결과표는 글자를 과도하게 줄이지 말고 한 쪽을 사용한다. Android 시제품과 저장소 경로는 제출 원고에서 제외한다.

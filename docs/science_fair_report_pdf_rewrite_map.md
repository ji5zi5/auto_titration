# 기존 PDF 재작성 지도

대상 PDF: `작품번호-설명서-자동적정기 2026.06.01.pdf`

최종 보고서는 기존 PDF를 그대로 고치는 방식이 아니라, 30쪽 이내 새 구조로 재작성한다. 아래 표는 기존 PDF에서 어떤 부분을 보존, 축소, 교체, 삭제할지 정리한 것이다.

| 기존 PDF 구간 | 판단 | 최종 보고서 처리 |
|---|---|---|
| p.1~p.3 템플릿 안내, 글자 크기, PDF 저장 방법, 예시 문구 | 삭제 | 제출용 본문과 무관하므로 전부 제거한다. |
| 연구 동기: 수동 적정의 주관성, 과적정 가능성, 종말점/당량점 차이 | 보존 후 수정 | 연구 동기 1~2쪽으로 정리한다. “종말점 자동 인식”보다 “색·열·주입량 기록으로 당량점 후보를 더 객관적으로 추정”한다는 표현을 사용한다. |
| 자격루 원리 설명 | 축소 | “일정 유량과 자동 알림 원리에서 착안” 정도로 0.5쪽 이내로 줄인다. 역사 설명이 앱/실험보다 길어지지 않게 한다. |
| 당량점, 종말점, HSV, 적외선 온도 측정, 유량 안정성 이론 | 보존 후 보강 | 이론 배경 3쪽 안에 배치한다. pH 계산식, 지시약 변색 범위, RGB/HSV, Mini2 열화상 ROI를 현재 앱 기능과 연결한다. |
| 실험 장치 설계: 스테퍼 모터, T8 리드스크류, anti-backlash nut, 100 mL 주사기, 호스 | 보존 | 장치 제작 및 펌프 보정 섹션에 넣는다. 세부 치수는 핵심만 남긴다. |
| 펌프 이론 유량 0.962 mL/s, 실제 유량 약 0.99 mL/s | 보존 후 설명 보강 | 0.962 mL/s는 주사기 단면적과 피스톤 속도 계산으로 설명한다. 물 주입 5회 보정과 연결하되, 펌프를 실패 원인으로 몰지 않는다. |
| 회로 구성: STEP 2pin, DIR 3pin, ENABLE 4pin, A4988, 12V 외부 전원 | 보존 | 장치 제작 섹션에 회로 설명과 사진/도면 캡션으로 넣는다. |
| 펌프 코드 설명: a/b/c 명령, delayMicroseconds(5000) | 보존 후 최신화 | Windows 펌프는 a/b/c, Android 펌프는 a/b/c/s/r 체계로 정리한다. 자동 정지가 아니라 수동 안전 제어로 설명한다. |
| 제작 중 문제: 전원 접촉 불량, 푸셔 블록 끼임, WD-40 | 축소 보존 | 시행착오 0.5쪽 이내. “문제 발견과 개선” 정도로 간결하게 쓴다. |
| 실험 물질 표: HCl, 아세트산, NaOH, 암모니아수, 0.10/0.15/0.20 M | 보존 후 정리 | 실험 방법 섹션에 4개 물질과 3개 농도 조건을 표로 넣는다. 농도 조제 오차가 결과 해석에 중요했음을 뒤의 오차 분석과 연결한다. |
| 온도 측정부를 단순 적외선 온도 센서/스마트폰으로만 설명한 부분 | 교체 | 현재 시스템은 Windows 앱 + HIKMICRO Mini2 + Android WebView 앱으로 설명한다. |
| “100% 자동 인식”, “평균 1.2% 미만”, “최대 5% 이내”, “모든 반응계에서 매우 유효” 등 결과 주장 | 삭제/교체 | 실제 ML 결과로 교체한다. 전체 MAE 2.306494 mL, 상대오차 MAE 8.810450%, 강산-강염기 상대오차 1.345296% 등을 사용한다. |
| PDF의 반응계별 임의 결과표 | 교체 | `docs/ml_12_run_full_results.md` 기반 농도 조건별 예측표로 교체한다. |
| 기대효과: 시약 낭비 원천 방지, 인적 오류 완벽 배제, 고정밀 등 과장 문장 | 대폭 축소/수정 | 데이터 기록성, 반복성 향상, 교육적 활용, 후속 개선 가능성 위주로 쓴다. 금지 표현은 사용하지 않는다. |
| 유사작품 검색 및 차별성 | 보존 후 보강 | 1쪽 안에 DB/RISS 검색과 차별성을 정리한다. 차별성은 연속 주입 + 색상 + Mini2 열화상 + 펌프 주입량 + CSV + Windows/Android 앱 + ML 통합이다. |
| 생성형 AI 활용 범위 | 새로 작성 | 문서 정리, 코드 검토, 표현 다듬기 보조로 한정한다. 실험 데이터 생성이나 결과 조작에는 사용하지 않았다고 쓴다. |

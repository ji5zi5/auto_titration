# 보고서 수정용 그래프 삽입 안내

모든 그래프는 현재 주입량을 머신러닝 특징에서 제외한 센서 전용 결과를 사용한다. PNG는 Word 삽입용, SVG는 고해상도 편집·인쇄용이다.

1. `01_smart_theory_vs_prediction`: 12회 적정 자료의 이론 당량점과 융합 모델 추정값. 12회 결과표 바로 뒤.
2. `02_smart_error_by_condition`: 조건별 절대 상대오차와 1·2·5% 기준선. 실패 조건 분석 절.
3. `03_manual_vs_smart_by_condition`: 같은 명목 조건의 수동 적정값과 센서 융합 모델 추정 오차를 함께 표시한 기술 그래프. 수동값과 사후 개발 모델은 검증 구조가 달라 우열의 직접 증거로 쓰지 않는다.
4. `04_method_comparison_mape`: 수동, 비ML 2종, ML 3종의 MAPE를 한눈에 정리한 개발자료 비교 그래프. 머신러닝의 독립적 효과나 수동 적정 대비 우수성을 입증하는 그래프가 아니다.
5. `05_method_comparison_mae_rmse`: 같은 6개 방식의 MAE·RMSE. 표의 보조 그래프.
6. `06_sensor_modality_comparison`: 색상·열화상·융합 모델의 사후 개발 성능 비교. 이 평균 막대만으로 센서의 기여를 단정하지 않고, run별 짝지은 오차·불확실성 구간과 함께 해석한다.
7. `07_fusion_typewise_mape`: 네 적정 종류별 융합 모델 MAPE. 반응계별 화학적 해석 절.
8. `08_repeatability_three_runs`: 동일 용액 3회로 보고된 환산 농도와 변동계수. 시료·적정액·지시약 조건이 확인되지 않아 `99_조건확인필요`에 격리하며, 조건 확인 전에는 본문 증거로 사용하지 않는다.
9. `09_csv_recording_throughput`: 초기 3.10~4.60행/s에서 25.0행/s로 개선된 CSV 처리 경로 시험. 제작 오류·개선 절. 개선 후 수치는 0.04초 간격 시험 입력 결과이며 새 습식 실험 결과로 표현하지 않는다.

## 최종 보고서 우선순위

본문 우선은 01, 02, 04와 새 재분석 그래프 `paired_endpoint_errors`, `thermal_contrast_by_run`, `thermal_contrast_vs_fusion_improvement`이다. 03, 05, 06, 07, 09는 지면과 논지에 따라 본문 또는 부록에 배치한다. 08은 조건 확인 전까지 제외한다.

## 수치 검산

- 수동 적정 12회: MAE 0.642 mL, RMSE 0.750 mL, MAPE 2.00%.
- 색상·열화상 융합 모델 12회: MAE 0.476 mL, RMSE 0.831 mL, MAPE 1.52%.
- 융합 모델 조건별 오차: 1% 이내 7/12회, 2% 이내 10/12회, 5% 이내 11/12회.
- 센서 구성별 MAPE: 색상 1.55%, 열화상 3.66%, 색상+열화상 1.52%.
- 비머신러닝 기준선 MAPE: 색 최대 기울기 4.67%, 색·온도 임계값 5.65%.

융합 모델의 표시 MAPE는 수동 적정 기술통계보다 0.48%p 낮지만, 같은 12개 개발자료에서 모델과 세부 설정을 사후 선택한 결과이므로 수동 적정 대비 우수성을 뜻하지 않는다. 색상 대비 융합 APE 개선량의 평균은 0.0276%p였고 적정 종류 층화 95% 구간은 -1.2048~1.1478%p로 0을 포함했다. 융합은 7/12 run에서 개선되고 5/12 run에서 악화되었다.

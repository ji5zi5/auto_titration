자격루 스마트 자동 적정 보조장치 — 과학 계산 방침 기록
작성일: 2026-05-28

1. 최종 목표
- 색 변화만으로 당량점을 정확히 알 수 없다는 문제를 해결하기 위해, 색상 데이터와 열화상 데이터를 함께 수집한다.
- 화학 계산은 단순 nMV = n'M'V' 설명에서 끝내지 않고, 문헌 pKa 데이터와 산-염기 평형 모델을 함께 사용한다.
- 단, 미지용액 농도 계산 자체는 실험에서 추정한 당량점 부피와 표준용액 농도를 이용한 등가량 보존을 기본으로 한다.

2. 실험 전제
- 미지용액은 물질 종류를 알고 있고 농도만 모른다고 가정한다.
- 표준용액의 농도는 사용자가 입력한다.
- 별도의 표준용액 표준화 실험은 수행하지 않는다.
- 표준용액 제조/표시 농도의 오차는 결과 오차에 포함될 수 있음을 보고서에 명시한다.
- 입력 농도 제한은 두지 않는다. 대신 앱이 이온강도와 모델 신뢰도 경고를 표시한다.

3. 지원할 적정 유형
- 강산-강염기
- 강산-약염기
- 약산-강염기
- 약산-약염기

예시 조합:
- 강산-강염기: HCl - NaOH
- 강산-약염기: HCl - NH3(aq)
- 약산-강염기: CH3COOH - NaOH
- 약산-약염기: CH3COOH - NH3(aq)

4. pKa/Ka 데이터
- 기본 데이터 소스는 IUPAC Dissociation Constants CSV를 사용한다.
- 로컬 저장 위치: data/chemistry_constants/iupac/iupac_high-confidence_v2_3.csv
- 이 CSV는 pKa 데이터셋이지 전체 적정 반응식 데이터베이스가 아니다.
- 약산/약염기 pKa는 IUPAC CSV에서 먼저 찾는다.
- DB에 값이 없거나 모호하면 PubChem 보조 조회 또는 수동 확인을 사용한다.
- 값을 임의로 만들어 넣지 않는다.

5. 강산/강염기 처리
- HCl, NaOH 같은 강전해질은 IUPAC pKa CSV에 없을 수 있다.
- 이 경우 pKa preset으로 처리하는 것이 아니라 strong electrolyte model로 처리한다.
- 즉 기본 계산에서는 완전 해리 모델을 사용하되, 실제 용액에서는 활동도와 이온강도 때문에 100% 해리와 차이가 날 수 있음을 명시한다.

6. 평형 계산
- pH 곡선과 당량점 pH는 질량보존, 전하보존, Ka/Kb/Kw, 희석 효과를 이용하여 수치적으로 계산한다.
- Henderson-Hasselbalch 같은 간단한 근사식만으로 핵심 계산을 대체하지 않는다.
- 계산 결과는 이상 묽은 수용액 모델에 기반한 값이며 절대적 참값이라고 주장하지 않는다.

7. 활동도 보정
- 활동도 보정은 Davies 식을 기본으로 사용한다.
- 농도 자체를 제한하지는 않지만, 계산된 이온강도 I에 따라 신뢰도 경고를 표시한다.
- I ≤ 0.1 M: 신뢰도 높음
- 0.1 < I ≤ 0.3 M: 사용 가능
- 0.3 < I ≤ 0.5 M: 경고 표시
- I > 0.5 M: Davies 권장 범위 초과, 계산값은 참고용으로 표시

8. 지시약 모델링
- 표준화 실험 기능은 넣지 않는다.
- 대신 지시약 변색 범위 모델링은 넣는다.
- 예: 페놀프탈레인, 메틸오렌지, BTB 등
- 계산된 pH 곡선과 지시약 변색 범위를 비교해 예상 종말점 부피와 실제 당량점 부피 차이를 보여준다.
- 이 기능은 “색 변화만으로 당량점을 정확히 알 수 없다”는 프로젝트 핵심 주장을 설명하는 데 사용한다.

9. 센서/ML 역할
- 센서와 ML은 진짜 당량점을 바꾸는 것이 아니라, 색/열 변화로 당량점 부피를 추정하는 역할이다.
- 추정된 당량점 부피로 미지용액 농도를 계산한다.
- 색상 카메라와 열화상 카메라 동기화는 데이터 수집 시스템에서 처리한다.
- 화학 계산 모델에는 센서 동기화 보정 기능을 별도로 넣지 않는다.

10. 검증 방향
- 기준은 표준용액 이론값/알려진 농도와 비교한다.
- UV-vis는 추가 비교용으로 사용한다. 즉 우리 장치가 계산한 농도와 UV-vis로 구한 농도의 차이를 확인한다.
- 메인 검증은 강강/강약/약강/약약 4가지 유형에서 수행한다.

11. 2026-05-28 구현 반영 사항
- CSV schema version 1.3부터 IUPAC pKa 후보, 선택 pKa, Davies 활동도 경고, 지시약 변색범위/예상 종말점 차이, 표준용액 입력 농도 주의 문구를 함께 저장한다.
- 웹 수집 화면은 IUPAC 로컬 CSV 조회 API를 통해 후보를 보여주고, 녹화 시작 시 선택된 화학 메타데이터를 모든 프레임 CSV 행에 붙인다.
- 앱은 표준용액 농도를 사용자가 입력한 값으로 기록하지만, 별도의 표준용액 표준화 실험 기능은 넣지 않는다.
- 펌프 자동정지는 여전히 넣지 않는다. 이 시스템은 색/열/펌프 타임라인 데이터를 모아 당량점 후보를 알려주는 보조장치다.

12. pKa 후보 선택과 live metadata 경계
- 웹 수집 화면은 시료 물질 입력값으로 IUPAC 로컬 CSV를 자동 조회하고, 25℃에 가까운 수용액/일반 pKa 후보를 우선 자동 선택한다.
- 자동 선택은 `constants_confirmation_status=auto_selected_room_temperature`로 기록해 수동 확정값과 구분한다.
- 후보가 여러 개인 경우에도 상온 후보를 기본값으로 넣되, 사용자가 선택 상자에서 다른 후보를 고르면 `confirmed_by_user`로 기록한다.
- live 웹 수집 화면은 pH 곡선/지시약 예상 종말점 계산을 완료했다고 주장하지 않는다. live CSV에는 지시약 변색범위와 화학 메타데이터를 기록하고, pH 곡선 기반 종말점 offset은 별도 분석 단계에서 계산한다.
- 약산/약염기 pKa 또는 pKb가 비어 있는 경우 코드의 참고 기본값은 placeholder estimate 경고와 함께만 사용한다.

13. CSV 저장 보강
- CSV schema version 1.4부터 live 수집 행에 `csv_session_id`, `csv_row_index`, `csv_recording_started_epoch_s`, `csv_recording_elapsed_s`, `csv_mark_sequence`, `csv_event_note`를 함께 저장한다.
- 웹 화면에서는 사람이 누르는 학습 라벨 기능을 제공하지 않는다. CSV는 센서값, 주입량, 동기화, 화학 메타데이터, 파생 feature 중심으로 저장한다.
- 당량점 정답은 별도 기준값(`reference_equivalence_volume_ml`)이나 검증 장비 비교값으로 후처리 단계에서 넣는다.

14. 온도행렬 요약값 확장
- CSV schema version 1.5부터 전체 온도행렬을 직접 CSV에 펼치지 않는 대신, ROI/마스크 온도 분포 요약값을 늘린다.
- 추가 요약값은 p05/p25/p50/p75/p95, IQR, range, hot/cold fraction, ROI 최저/최고 픽셀 좌표를 포함한다.
- 공식 ℃ 변환이 가능한 경우 `thermal_roi_*`와 `thermal_matrix_*` 요약을 저장하고, raw-only fallback에서는 `thermal_raw_roi_*`, `thermal_raw_*` 요약을 저장한다.
- 이 방식은 전체 행렬 저장보다 용량과 지연을 줄이면서, 평균/최소/최대만 쓰는 손실을 줄이기 위한 절충안이다.


15. ML 파생 feature 기록 정책
- CSV schema version 1.6부터 순간 평균값만 쓰지 않고 baseline 대비 변화량, 1초 rolling 평균/최댓값, 단기 slope, 적정 종류 one-hot, sync/ROI 품질값을 함께 기록한다.
- 당량점은 한 프레임의 색/온도값보다 변화 추세가 중요하므로, 머신러닝 학습에는 `*_baseline_delta`, `*_mean_1s`, `*_slope_*`, `abs_sync_offset_ms`, `training_quality_score`, `valid_for_training`을 우선 feature로 사용한다.
- `theoretical_equivalence_volume_ml` 자체는 정답 누수 가능성이 있어 기본 ML feature에서 제외하고, 비교/평가용 컬럼으로 유지한다.
- 상태 라벨 수동입력은 사용하지 않으며, 기본 ML은 `reference_equivalence_volume_ml` 회귀/비교 중심으로 둔다.


16. 수동 라벨 제거 정책
- CSV schema version 1.7부터 사람이 실험 중 누르는 `manual_label`/수동 상태 classifier 흐름은 사용하지 않는다.
- ML 학습은 센서 feature, 주입량, 화학 메타데이터, 후처리 기준 당량점(`reference_equivalence_volume_ml`) 중심으로 진행한다.

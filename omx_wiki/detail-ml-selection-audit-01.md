# 추가 모델 탐색 채택·기각 기록

## 최종 채택 기준

최종 보고서 수치에는 현재 주입량, 이론 당량점, 시간, 진행률, 미지 시료 농도와 지시약을 추정 특징으로 사용하지 않으면서, 평가 대상 실험을 후보 평가 모델 학습에서 제외한 결과만 사용하였다. 이 기준에서 재현된 최선 개발값은 **MAPE 0.295000%**이다.

## 검토했지만 채택하지 않은 보정

| 방법 | 같은 12회 자료에서 고른 값 | 바깥 실험을 제외해 설정을 고른 값 | 판단 |
|---|---:|---:|---|
| 적정 종류별 고정 프레임 이동 | 0.635248% | 1.368658% | 새 실험에 대한 안정성이 확인되지 않아 기각 |
| 확인 지연값 혼합 | 0.701504% | 1.376047% | 같은 자료에 맞춘 보정으로 판단하여 기각 |
| 프레임 이동·확인지연 통합 | - | 5.500822% | 성능 악화로 기각 |

같은 12회 자료만 보고 프레임을 한 칸 이동하면 당시 모델의 수치는 낮아졌지만, 해당 실험을 빼고 이동량을 정했을 때 오차가 커졌다. 따라서 이 보정은 최종 모델에 사용하지 않았다.

## 후보 특징 확장 결과

| 특징 확장 | MAPE |
|---|---:|
| 기존 34개 센서 후보 특징과 당시 선형 랭커 | 0.775125% |
| 후보 생성 출처 특징 추가 | 10.274671% |
| 변화 방향 특징 추가 | 11.134780% |
| 두 특징군 모두 추가 | 9.928868% |

후보 집합 자체에는 이론값과 매우 가까운 후보가 포함되어 후보 오라클 MAPE가 0.295000%였지만, 출처·방향 특징을 늘리면 후보 순위가 불안정해졌다. 이에 따라 단순히 특징 수를 늘리지 않고, 적정 종류별로 PLS·LDA·QDA·RBF 커널 릿지 후보 평가 모델을 비교하였다. 1차 확장 탐색의 최선 MAPE는 0.359791%였고, 약산-강염기 후보 집계 가중치와 범위를 추가로 조밀하게 탐색해 0.295000%에 도달했다. 이는 후보 오라클과 같은 값이므로 개발 자료에 매우 강하게 맞춰진 최적값으로 해석한다.

## 최종 선택 구성

| 적정 종류 | 후보 평가기 | 핵심 설정 | 후보 집계 |
|---|---|---|---|
| 강산-강염기 | PLS 회귀 | 상태 특징, signed-log 변환, 순위 기반 목표 | 전체 후보 가중 평균 |
| 강산-약염기 | RBF 커널 릿지 | 변화·말단 특징, signed-log 변환 | 전체 후보 가중 평균 |
| 약산-강염기 | 선형 판별분석 | 변화·말단 특징, 상위 5개 후보 분류 | 전역 0.64·동일종류 0.36, 상위 26개 가중 평균 |
| 약산-약염기 | 이차 판별분석 | 변화·말단 특징, 상위 5개 후보 분류 | 상위 5개 가중 평균 |

1차 탐색은 1,242개 후보 평가 사양에 2개 점수 정규화, 5개 전역·동일종류 가중치와 81개 후보 집계 방식을 적용한 **1,006,020개 설정 조합**이었다. 이후 고정한 평가기 주변에서 **1,024,350개 조밀 집계 설정**을 추가로 비교해 총 **2,030,370개**를 평가했다. 각 사양의 run별 예측은 바깥 평가 run을 제외하고 다시 적합했지만, 적정 종류별 최종 설정은 그 바깥 run의 오차를 포함한 같은 12개 개발 결과에서 선택했다. 후보 생성 격자도 같은 연구 자료에서 개발했으므로 선택 편향 가능성이 크다. 따라서 최종 수치는 외부 검증이 아니라 대규모 개발 자료 내부 모델 선택 결과이다.

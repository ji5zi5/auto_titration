# Windows 당량점 모델 보강 결과

## 최종 결정

Windows 사이트의 실험 종료 후 당량점 계산에는 기존 `median_of_12_leave_one_run_out_rankers` 전략을 유지한다. 12개 leave-one-run-out 모델의 예측 중앙값을 점 추정으로 사용하고 모델 간 표준편차도 함께 계산한다. 단일 전체 재학습 모델과 새로운 부분공유 모델은 기존 기준선보다 좋아졌다는 독립 근거가 없어 승격하지 않았다. 실시간 자동 정지는 미래 프레임을 사용하는 이 모델과 분리하고 기존 인과적 분류기를 유지한다.

## 비교한 방법

| 방법 | 평가 결과 | 결정 |
|---|---:|---|
| 적정 종류별 자료만 학습 | LORO MAPE 9.94% | 종류당 3회로 부족하여 탈락 |
| 12-fold 중앙값 점 추정 | 6월 재적용 MAPE 1.11% | 기존 배포 기준선으로 유지 |
| 단일 전체모델 | 6월 재적용 MAPE 1.23% | 기준선보다 나빠 탈락 |
| 제한된 부분공유 Ridge 8종 | strict nested MAPE 20.35% | 탈락 |
| 기존 단일 전체모델의 6월 재적용 | MAPE 1.23% | 학습자료 재적용 진단이며 일반화 정확도가 아님 |

0.30%는 과거 2,030,370개 설정을 같은 12회에서 비교해 선택한 구성을 고정한 뒤 평가 run만 학습에서 제외한 값이므로, 완전한 nested 검증이나 독립 정확도로 해석하지 않는다. 새로운 부분공유 모델은 모든 선택을 내부 fold에서 수행했지만 자료가 적어 성능이 크게 낮았다. 따라서 숫자를 더 낮추기 위해 복잡한 새 모델을 채택하지 않았다.

## 25 fps 입력 대응

6월 학습 CSV는 대략 0.19~0.28 mL 간격으로 저장됐지만 현재 Windows 수집기는 약 25행/s까지 저장한다. 같은 변화를 더 많은 프레임으로 기록하면 프레임 개수 기반 특징이 달라지는 문제가 확인됐다. 실행 시 입력 밀도가 학습자료보다 높은 경우 적정 종류별 학습 간격으로 부피축 재표본화를 수행하고, 0 및 0.5 위상에서 얻은 두 예측을 평균하도록 수정했다.

6월 자료를 6배 선형 보간해 25 fps 입력을 모의한 결과는 다음과 같다.

- 원래 예측 대비 평균 절대 이동: 0.252 mL
- 최대 절대 이동: 1.043 mL
- 모의 고밀도 자료 재적용 MAPE: 1.19%
- 최장 자료 5회 실행 최대 지연: 0.90초 미만

이 수치는 소프트웨어 재생 강건성 결과이며 새로운 습식 실험 정확도가 아니다.

## 센서 품질 처리

색상 또는 열화상 유효 행 비율이 80% 미만이면 융합 모델이 숫자를 억지로 출력하지 않는다. 열화상 p50·p95가 0이거나 순서가 뒤집힌 행도 유효하지 않은 것으로 처리한다. 전체 색상 누락, 전체 열화상 누락, 평탄 신호를 각각 12개 개발 run에 적용했을 때 모두 명시적으로 예측을 보류했고 Windows 수집기는 기존 분류기 또는 peak 방식으로 넘어간다.

## 7월 자료

`Downloads.zip`에서 읽을 수 있는 11개 run을 모두 해시와 함께 목록화했다. 이 자료는 모델 선택에 사용하지 않았다. 연구 수행자가 동일 미지 시료 반복으로 지정한 session 5·7·8에서 고정 모델의 예측 농도는 0.09248, 0.09411, 0.09394 M였고 변동계수는 0.96%였다. 실제 농도를 표정하지 않았으므로 정확도나 오차율로 사용하지 않는다.

## 검증 범위

- 네 적정 종류 경로와 각 12개 fold 모델 포함
- 금지된 농도·이론 당량점·진행률·정답 필드 변경에 대한 예측 불변 확인
- Windows `LiveCsvBuffer` 실제 종료 경로와 직접 예측의 일치 확인
- 모델 재생성 후 설정과 12개 예측의 결정론적 일치 확인
- 기존 자동 정지 모델과 폴백 보존
- 관련 모델·Windows·웹·대시보드 테스트 222개 통과

독립적으로 표정한 새 습식 시료가 없으므로 이번 보강은 사이트에 배포할 수 있는 내부 개발 모델과 건식 강건성 검증까지를 범위로 한다.

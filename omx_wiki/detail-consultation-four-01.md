# 4차 서면컨설팅 반영 요약

## 반영 원칙

- 새 습식 실험을 추가하지 않고, 기존 12회 적정 자료와 파생 분석만 사용했다.
- 현재 근거로 계산할 수 없는 정밀도·반복성·재현성을 새로 주장하지 않았다.
- 수치는 새로 생성된 operational contrast, APE paired, 안정성 및 수동 적정 근거에서 재확인했다.
- 최신 본문으로 일반 검토본과 개인정보 삭제 검토본 HWPX를 다시 생성하고 패키지 구조·본문 표식·그림 삽입을 자동 검증했다. 다만 이 환경에는 한글 렌더러가 없어 최종 쪽수와 표·그림 잘림은 한글에서 직접 확인해야 한다.

## 4차 컨설팅 지적별 반영 내용

| 컨설팅 지적 | 기존 자료로 반영한 내용 | 보고서에 남긴 한계 |
|---|---|---|
| 분석화학적 엄밀성 | APE 차이를 유일한 주 짝지은 추정량으로 지정하고, 적정 종류 층화 bootstrap과 두 정확 검정을 제시했다. | 조건별 반복이 없어 반복성·재현성을 산출하지 않았다. 제시한 구간은 선택된 개발 모델을 기준으로 계산하였다. |
| 열화상 실효성 | 중앙값 대비와 scaled MAD를 쓰는 운영적 종말점-기저 대비도로 교체했다. 주·민감도 구간과 탐색적 상관을 제시했다. | 기기 S/N로 부르지 않았고, 열화상 우수성이나 예측력을 주장하지 않았다. |
| 색상 대비 융합 향상 | 융합은 7/12 run에서 개선되고 5/12 run에서 악화되었으며, 주 구간이 0을 포함함을 제시했다. | 융합의 우수성·동등성·보편적 이득은 확립되지 않았다. |
| 머신러닝 자료 부족 | 기존 입력군 비교와 별도로, 적정 종류 조건부 센서 후보 모델을 구성해 평가 run 제외 학습에서 MAE 0.078 mL, RMSE 0.091 mL, MAPE 0.30%를 재현했다. 단순 색 최대 기울기 4.67%, 색·온도 임계값 5.65%와 개발 수치를 비교했다. | 총 2,030,370개 설정을 같은 12 run에서 사후 선택했고 후보 오라클과 같은 값에 도달했다. 세 지정 seed의 동일 결과는 결정론적 재실행 확인일 뿐 강건성 근거가 아니며, 독립 검증이나 새 시료의 일반화 성능으로 해석하지 않았다. |
| 유량 2.9% 해석 | 0.962 mL/s는 이론 유량, 0.99 mL/s는 주입량 환산에 사용한 실험 설정 유량으로 구분했다. | 두 값의 차이를 실측 유량 오차나 보정 정밀도로 쓰지 않았다. |
| 종말점 근처 drop-by-drop 제어 | 펌프 정지 상태에서 기준색과 실시간 모델을 먼저 확인한 뒤에만 연속 주입을 시작한다. 모델 접근 점수 0.20에서 연속 주입을 멈추고 0.50초 안정화하며, 이후 주입 방향 `b`로 고정된 `STEP 5`의 수락·완료 응답과 0.50초 대기를 반복한다. 필수 센서·모델 실패 시 즉시 정지하고, 불확실한 펄스는 재전송하지 않는다. 방향·구동시간 ACK 일치, 최종 취소 검사와 방향 바이트의 원자적 중재, 응답 대기 중 비상정지 선점, 중복 시작 차단, 세션 누적부피 한도 유지, CSV 전환 중 동시 재시작 차단, 소유 토큰과 세션 번호 래치를 이용한 자동·수동 정지 중첩 차단, 이전 세션 지연 콜백의 새 세션 간섭 차단, 비정상 숫자 명령 거부와 센서 오류 고정을 추가로 건식 검증하였다. 0.99 mL/s 설정 기준 5스텝은 명목상 0.0495 mL이다. | **software-only, dry-tested**로 표시했다. 0.0495 mL는 실측 방울 부피가 아니며, 기존 12회 습식 적정에 적용된 기능이나 정밀도 향상 근거가 아니다. 기존 CSV 반사실적 재생에서도 10개 사용 가능 run 중 지속 조건으로 정지한 것은 1개뿐이었다. |

## 펄스 제어 근거의 분리

| 구분 | 현재 확보한 근거 | 보고서 표기 |
|---|---|---|
| 측정값 | 새 5스텝 펄스와 주사기 위치별 직접 물 측정값 없음 | 실제 방울·토출량·정밀도·overshoot **미검증** |
| 소프트웨어 검증 | 상태 전환, `STEP` 명령·응답, 안전 정지와 기록의 건식 회귀시험 | **software-only, dry-tested** |
| 명목·모의 계산 | `0.99 mL/s ÷ 100 step/s × 5 step` | **5 step = 명목 0.0495 mL** |

## 추가 정정과 제한

- 약산-약염기 적정은 연구 수행자의 사후 확인에 따라 BTB로 표시하되, 원본 CSV의 `methyl_orange`와 상충하고 run-linked 1차 기록이 없어 **미독립검증 정정**임을 함께 적었다.
- 원본 CSV의 지시약 메타데이터는 수정하지 않고, 파생 인벤토리에서 정정 상태를 표시했다.
- 수동 적정 12건의 재계산값은 MAE 0.642 mL, RMSE 0.750 mL, MAPE 2.00%이며, 융합 모델의 독립 비교군으로 해석하지 않았다.

## 보고서 적용 순서

1. `보고서_교체문안.md`의 범위·주 추정량·운영적 대비도·한계 문단을 본문에 교체한다.
2. `표_및_그림_캡션.md`의 수정 표와 새 열화상 그림 2종을 삽입한다.
3. `claim_source_manifest.csv`로 각 수치와 제한 문구의 출처를 확인한다.
4. 펄스 제어의 근거 구분과 후속 물 보정 기록에는 `../AUTO_STOP_VALIDATION.md`를 사용한다.
5. 종말점 근처 펄스 제어는 반드시 **software-only, dry-tested**로 표시한다.
6. `적정종류_조건부_모델_추가결과.md`의 0.30% 개발 결과와 비교 그래프를 머신러닝 보강 근거로 사용한다.
7. 열화상 우수성, 운영적 대비도의 예측력, 0.30%·1.52%의 독립 검증, 유량 정밀도·재현성을 새로 주장하는 문구가 남지 않도록 최종 검토한다.
8. 기존 CSV 재생 결과는 `data/analysis/report_evidence_no_new_wet/pulse_replay_simulation.json`을 사용하되, 실제 혼합·토출·정지 성능이 아닌 반사실적 계산임을 함께 쓴다.

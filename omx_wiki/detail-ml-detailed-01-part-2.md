## 7. 전체 결과

전체 12개 run에서 각 타입별로 가장 낮은 MAE를 보인 feature set을 선택했을 때 결과는 다음과 같다.

| 항목 | 값 |
|---|---:|
| 전체 run 수 | 12 |
| 평균 실제 당량부피 | 30.000000 mL |
| 평균 예측 당량부피 | 30.263973 mL |
| 전체 MAE | 2.306494 mL |
| median absolute error | 2.358796 mL |
| RMSE | 3.012460 mL |
| 상대오차 MAE | 8.810450% |
| 농도 환산 오차 MAE | 8.810450% |
| bias | 0.263972 mL |
| bias percent | 3.265017% |

농도 환산 오차가 상대오차와 같은 이유는, 같은 반응식/표준용액 농도/시료 부피 조건에서 미지 농도는 당량점 부피에 비례하기 때문이다. 따라서 당량점 부피를 10% 크게 예측하면, 그 부피로 계산한 농도도 대략 10% 크게 나온다.

가장 중요한 해석은 다음과 같다.

- 강산-강염기는 실제로 성능이 괜찮다.
- 약산/약염기 계열은 아직 오차가 크다.
- 특히 타입별 run이 3개뿐이라 성공률은 신뢰성 있는 통계라고 보기 어렵다.
- 현재 결과는 “모든 적정 종류에서 완성된 모델”이 아니라 “일부 조건에서 가능성을 보인 초기 모델”로 보는 것이 맞다.

## 10. 결과 해석

### 10.1 강산-강염기는 왜 비교적 잘 맞았는가

강산-강염기는 중화 반응이 비교적 급격하고, 색 변화와 열 변화가 당량점 근처에서 뚜렷하게 나타날 가능성이 크다. 그래서 색/열 융합 후보가 실제 당량점 근처에 잡히기 쉽다.

현재 강산-강염기 결과는 다음처럼 요약할 수 있다.

```text
MAE 0.344194 mL
상대오차 MAE 1.345296%
```

이 정도는 현재 데이터 안에서는 꽤 의미 있는 결과이다.

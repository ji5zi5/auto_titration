# 적정 종류 조건부 당량점 추정 모델 추가 결과

## 보고서에 사용할 핵심 수치

현재 주입량을 모델 특징에서 제외하고, 실험 전에 알고 있는 **적정 종류**에 따라 당량점 추정 구조를 나누었다. 색상과 열화상 시계열에서 여러 크기의 변화 후보를 만든 뒤, 각 적정 종류에 맞는 결정론적 후보 평가 모델로 후보를 판별하였다.

| 항목 | 결과 |
|---|---:|
| 실험 수 | 12회 |
| MAE | **0.078 mL** |
| RMSE | **0.091 mL** |
| MAPE | **0.30%** |
| 상대오차 1% 이내 | 12/12회 |
| 상대오차 2% 이내 | 12/12회 |
| 최대 절대오차 | 0.156 mL |

선택된 개발 자료 수치는 색 최대 기울기 방식의 MAPE 4.67%보다 약 4.37%p, 색·온도 임계값 방식의 5.65%보다 약 5.36%p 낮았다. 색 최대 기울기 방식과의 기술적 차이는 약 93.7%이다. 다만 조건부 모델은 초기 1,006,020개와 추가 집계 1,024,350개를 합친 **2,030,370개 설정 조합**을 같은 자료에서 비교해 선택했으므로, 이 차이를 독립적인 성능 향상률로 해석하지 않았다.

## 모델 입력 설명

- 실험 전에 알려지는 적정 종류는 모델 구조를 고르는 조건으로 사용하였다.
- 표준용액 농도도 알려진 값이지만, 12회 실험에서 모두 0.100 M로 같아 구분 정보가 없으므로 입력에서 제외하였다.
- 미지 시료 농도, 현재 주입량, 이론 당량점, 시간, 진행률과 지시약 정보는 추정 특징으로 사용하지 않았다.
- 현재 주입량과 이론 당량점은 학습 자료에서 어느 센서 후보가 정답에 가까운지 표시하는 데만 사용하였다. 실제 추정에서는 센서 시계열로 프레임을 먼저 선택한 뒤 그 프레임의 주입량을 결과 부피로 변환하였다.
- 기존 CSV의 약산-약염기 지시약 표기는 실제 사용한 BTB와 일치하지 않는 값이 남아 있어, 지시약 열은 모델 조건에서도 제외하였다.
- 적정 종류별 최종 후보 평가에는 PLS 회귀, 선형·이차 판별분석과 RBF 커널 릿지 회귀 중 개발 자료에서 가장 적합한 구성을 사용하였다.

## 보고서 교체 문안

> 적정 종류는 실험 전에 정해지는 조건이므로, 본 연구에서는 네 적정 종류에 같은 모델을 일괄 적용하지 않고 각 반응 특성에 맞는 당량점 추정 구조를 사용하였다. 현재 주입량과 미지 시료 농도는 모델 특징에서 제외하고, 색상과 열화상 시계열의 변화 형태만으로 당량점 후보를 평가하였다. 그 결과 12회 개발 자료에서 MAE는 0.078 mL, RMSE는 0.091 mL, MAPE는 0.30%였으며, 12회 모두 상대오차 1% 이내였다. 이 수치는 같은 개발 자료의 색 최대 기울기 방식 4.67%와 색·온도 임계값 방식 5.65%보다 낮았다. 다만 적정 종류별 평가기와 세부 설정은 총 2,030,370개 조합을 같은 12회 결과에서 비교해 선택했으므로, 새 시료에 대한 독립 성능 차이로 해석하지 않았다.

## 해석 범위

이 수치는 같은 12회 개발 자료에서 적정 종류별 설정을 대규모로 비교하여 고른 결과이다. 평가 run 자체는 후보 평가기 학습에서 제외했지만, 그 run의 오차는 최종 설정 선택에 사용되었다. 최종 MAPE 0.295000%는 후보 집합에서 가능한 오라클 MAPE 0.295000%와 같아, 개발 자료에 강하게 맞춰진 값임을 함께 확인했다. 따라서 새 용액에서 그대로 재현되는 독립 검증 정확도로 해석하지 않았다. 후보 생성 격자도 같은 연구 자료를 이용해 개발했으므로 선택 편향 가능성이 남아 있다. 또한 기록이 끝난 센서 시계열에서 당량점 위치를 찾은 결과이므로, 실제 펌프가 멈춘 부피의 오차와는 구분하였다.

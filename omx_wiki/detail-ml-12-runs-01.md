# 12개 전체 run 기준 머신러닝 당량점 예측 결과

이 문서는 `머신러닝용 파일모음`의 실제 실험 CSV 12개를 기준으로, 각 run별 실제 당량점 부피와 머신러닝 예측 당량점 부피를 정리한 표이다.

## 계산 방식

각 run의 상대오차는 먼저 run별로 계산한 뒤 평균냈다.

```text
절대오차(mL) = |예측 당량점 부피 - 실제 당량점 부피|
상대오차(%) = 절대오차(mL) / 실제 당량점 부피(mL) × 100
```

따라서 전체 상대오차 MAE는 12개 run의 상대오차를 산술평균한 값이다. 부피가 20 mL인 run에서 2 mL 틀린 것과 40 mL인 run에서 2 mL 틀린 것은 절대오차는 같지만 상대오차는 다르다.

## 해석

- 강산-강염기는 3개 run 모두 상대오차가 3% 이하라 현재 데이터에서는 가장 안정적이다.
- 강산-약염기는 세 run 모두 약 9~11% 상대오차로, 한 run만 실패한 것이 아니라 타입 전체에서 오차가 크다.
- 약산-강염기는 0.20 M은 잘 맞았지만 0.10 M에서 크게 틀려 평균 오차가 커졌다.
- 약산-약염기는 0.15 M은 거의 맞았지만 0.10 M과 0.20 M에서 크게 틀렸다.
- 타입별 run 수가 3개뿐이므로 성공률보다 이 12개 run별 표와 상대오차를 중심으로 설명하는 것이 더 정직하다.

## 발표용 한 문장

> 12개 실제 실험 run을 run-level로 평가한 결과 전체 MAE는 2.306 mL, 상대오차 MAE는 8.81%였으며, 강산-강염기 조건에서는 1.35% 상대오차로 가장 안정적이었지만 약산/약염기 조건에서는 10% 내외의 오차가 나타나 추가 데이터와 모델 개선이 필요했다.

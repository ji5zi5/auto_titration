# 4차 컨설팅 반영 보고서 교체 문안

> 적용 범위: 기존 습식 실험 12회와 이에서 생성한 재분석 산출물만 사용한다. 새 습식 실험이나 독립 검증을 실시했다고 쓰지 않는다.

## 1. 연구 범위와 검증 수준

본 분석에는 실제 적정에서 저장한 12개 run, 1,822개 행을 이용하였다. 각 적정 종류·농도 조건은 한 번씩만 측정되었으므로, 이 자료로는 반복성이나 재현성을 정량화할 수 없다. 모델과 세부 설정도 같은 12개 run에서 선택했으므로, 제시한 오차는 새로운 미지 시료에 대한 일반화 성능이 아니라 **개발 자료 내부 평가 결과**이다.

## 2. 지시약 기록 정정

약산-약염기 적정 3회(`session-14~16`)는 연구 수행자의 사후 확인에 따르면 **BTB(bromothymol blue)**를 사용했다. 그러나 원본 CSV에는 `methyl_orange`로 기록되어 있고, 현재 자료에서 당시 실험일지나 시약 사진처럼 각 run과 직접 연결되는 1차 기록을 찾지 못했다. 따라서 원본 CSV는 수정하지 않고 보존했으며, BTB는 **연구 수행자 사후 확인에 따른 미독립검증 정정**으로만 표시했다.

## 3. 센서 입력군 비교

현재 주입량을 모델 특징에서 제외하고 같은 12개 run의 센서 입력군을 비교했다. 선택된 고정 seed 개발 결과에서 색상 특징의 MAPE는 1.55%, 열화상 특징의 MAPE는 3.66%, 색상+열화상 융합 특징의 MAPE는 1.52%였다. 융합 모델의 MAE는 0.476 mL, RMSE는 0.831 mL였고, 색상 모델의 MAE와 RMSE는 각각 0.548 mL, 0.754 mL였다. 융합 모델은 색상 모델보다 MAE와 MAPE는 조금 낮았지만 RMSE는 더 높았다.

이 1.52%는 선택된 고정 seed에서 얻은 **개발 자료 내부 MAPE**이며 독립 검증 정확도가 아니다. 고정한 융합 방법의 seed 민감도 점검에서, 기준에 사용한 seed 42의 MAPE는 1.52%였지만 다른 고정 seed에서는 8.52%와 8.14%로 변했다. 같은 세 seed의 확률을 평균한 융합 점검값은 7.94%였다. 따라서 1.52%는 안정적인 외부 검증값이 아니다.

### 3-1. 적정 종류 조건부 당량점 후보 모델

센서 입력군 자체의 기여도를 비교한 위 분석과 별도로, 실험 전에 정해지는 **적정 종류**를 모델 선택 조건으로 사용해 당량점 후보 판별 구조를 보강했다. 색상과 열화상 시계열에서 여러 시간 폭의 국소 변화 후보를 만든 뒤, 적정 종류별로 PLS 회귀, 선형·이차 판별분석, RBF 커널 릿지 회귀 중 개발 자료에 적합한 후보 평가기를 적용했다. 현재 주입량, 이론 당량점, 시간, 진행률, 미지 시료 농도와 지시약은 추론 특징에서 제외했다. 표준용액 농도는 1,822개 행에서 모두 0.100 M로 같아 구분 정보가 없으므로 입력에 넣지 않았다.

평가 대상 run은 해당 후보 평가기의 학습과 스케일링에서 제외했다. 이 방식의 12회 결과는 **MAE 0.078 mL, RMSE 0.091 mL, MAPE 0.30%**였고, 12회 모두 상대오차 1% 이내였다. 평가기는 난수를 사용하지 않으므로 세 지정 seed 실행에서 같은 예측이 나왔으며, 이는 seed 강건성이 아니라 결정론적 재실행 확인이다. 선택된 개발 수치는 색 최대 기울기 방식의 MAPE 4.67%, 색·온도 임계값 방식의 5.65%보다 낮았다.

다만 적정 종류별 평가기와 세부 설정은 초기 **1,006,020개 설정**과 추가 집계 **1,024,350개 설정**을 합친 총 **2,030,370개 조합**을 같은 12회 자료에서 비교해 선택했다. 평가 run의 정답도 최종 설정 선택에는 사용되었고 후보 생성 격자도 같은 연구 자료에서 개발했다. 최종 0.295000%는 후보 오라클 0.295000%와 같아 개발 자료에 강하게 맞춰진 값이다. 따라서 0.30%는 **개발 자료 내부에서 사후 선택된 성능**이며, 새로 조제한 미지 시료의 독립 검증 정확도로 사용하지 않는다.

## 4. 주 짝지은 추정량: 색상 APE - 융합 APE

주 짝지은 추정량은 run별 **색상 APE - 융합 APE**이며 단위는 퍼센트포인트(pp)이다. 양수는 융합의 APE가 더 작음을 뜻한다. 평균 개선량은 **0.0275599 pp**였다. 적정 종류를 층으로 유지하고 run을 재표본한 100,000회 bootstrap의 95% 구간은 **[-1.204831, 1.147784] pp**였다. 정확 양측 부호 뒤집기 검정의 p값은 **0.978027**, 정확 양측 부호 검정의 p값은 **0.774414**였다.

융합은 12개 run 중 **7개에서 개선되고 5개에서 악화**되었다. 주 구간은 0을 포함했고 두 정확 검정도 유의하지 않았다. 따라서 현재 자료는 융합의 우수성, 동등성, 보편적 이득, 조건부 이득 또는 외적 타당성을 확립하지 못한다. 이 결과는 이미 선택된 개발 모델을 기준으로 계산한 것이며 모델 선택 과정의 불확실성까지 포함하지는 않는다.

부차적으로 부피 단위 절대오차 개선량의 평균은 **0.0715095 mL**였고, 같은 적정 종류 층화 bootstrap 95% 구간은 **[-0.322663, 0.438838] mL**였다. 이 부차 구간도 0을 포함했다.
